name: pnds-handoff
description: Complete all current tasks in a PNDS creation handoff, then verify, report, and archive the results.
---

Read `AGENTS.md` if present, `docs/creator-handoff.md`, and existing project terminology and design documents; follow their definitions and consult PNDS contracts through project references or the [reference index](https://github.com/xO-xN/PNDS-App/blob/main/docs/en/reference/README.md).
Complete every current task in the handoff, following its confirmed scope, decisions, and acceptance criteria.
Run applicable checks and report actual results; pending sound, visual, or device review by the creator belongs in history and does not keep implemented and checked tasks active.
Archive the full previous handoff and implementation/check report under `docs/handoff-history/` before removing completed tasks or replacing superseded rules; keep only unimplemented or blocked work with reasons in the current handoff and preserve existing history.
