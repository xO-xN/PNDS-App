# 创作交接单

App 记录创作意图，外部 agent 实施任务并在此更新状态和验收证据。接续前先读取根目录 AGENTS.md，按其中的指针优先读取已安装 PNDS App 的平台契约。

任务采用 App 的交接格式：稳定标识 `<!-- pnds-task:<UUID> -->`、二级任务标题、`Status / 状态`，以及 `Intent / 意图`、`Files / 涉及文件`、`Acceptance / 验收条件` 三个三级小节。状态由实际工作和证据决定；App 写入 pending、in-progress 或 blocked 不代表外部 agent 已完成。

追加新任务时保留既有内容；接续或更新任务时保留稳定标识，并在对应任务下补充实现与验证证据。README 同步任务必须核对保存版本、保留封面格式与未知内容，并由创作者复核双语。模块接线任务须分别记录文件加入、接线和实际验证。

手机交互、QR 或连接任务须按 AGENTS.md 的对应指针读取契约，记录实际浏览器 API、HTTPS 需求判断、manifest 声明、Host 选择的网址，以及 QR／连接验证结果。普通工程按 HTTP 验证；安全上下文作品的可信 HTTPS、浏览器权限与真实设备能力单独记录，未做的检查保持待验收。
