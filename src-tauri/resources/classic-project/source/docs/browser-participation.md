# 统一演奏入口适配

适用于 PNDS App v1.7.0-beta.3 的浏览器接入协议 1。普通局域网浏览器与原生
PNDS Client 从同一池主根地址明确进入；静态脚本、p5、Socket.IO 都由本地来源提供。
模板的普通双推子、claim 恢复、拒绝／重置、monitor 和既有 HTTPS 路径保持。

浏览器确认上下文使用 Host/工程持久键，每场授权只用于本场资源与实时连接。
页面准备报告来自实际画布和已连接传输，不冒充工程接纳身份。不同地址／浏览器数据
不承诺自动迁移。原生来源继续由 App 隔离并保留已有未加前缀的 claim 键；HTTP 不扩展安全上下文 API 能力。

验证：`npm run check`、`npm test`；App 中还通过实际公开 Host 启动、浏览器确认和
独立 PNDS Client 验证 Template／新建 Classic。App 与实体手机、声音、签名安装和
无公网场地的最终行为仍需用户实机验收，不以机制夹具代替。
