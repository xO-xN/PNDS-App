# 新建时确认 GitHub 目标，保存版本以本机为默认

创作者从一个表单开始创作。新建时默认显示公开目标，由「创建并公开到 GitHub」确认初始工程版本的公开范围。PNDS 代办从官方模板建仓、上传和绑定。私有和暂不上传从折叠选项可选。工程先在本机建立，创作者可以离线工作，首次上传中断后沿用已确认的目标与版本。本决定替代 [ADR-0019](./0019-creator-github-template.md) 中 App 新建工程需要创作者手动往返浏览器建仓和选仓的步骤，沿用模板来源、核验和历史保留约束。

版本是日常创作界面的主入口。创作者默认在本机保存，按需将已保存历史备份到 GitHub。自动备份按创作路线授权，公开工程也可以在本机试验新路线。旧版工程级开关无法确定授权的路线，迁移时保留绑定、历史和待传记录并暂停自动备份，由创作者为对应路线重新开启。本决定调整 [ADR-0018](./0018-creator-github-backup.md) 的页面层级和自动备份范围，沿用 [ADR-0011](./0011-creator-git-version-navigation.md) 的版本保存、切换和分叉语义。
