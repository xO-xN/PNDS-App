# App 共享包与工程自带依赖并存

v1.6.2 规划引入由 PNDS App 保存、工程显式引用的共享依赖库，创作模式将「加入共享包」作为常规入口；浏览器库与选定 Node 依赖同版交付，工程仍可自带依赖。引用共享包的 `.pnds` 只分发引用，不重复携带 App 提供的库。模型因使用不普遍而由工程自带，随工程分发；这不改变可编辑标准模块源码归工程维护的边界。

2026-10-12 最新决定：每项共享库仅打包一个尽量新的版本，先验证 Inarticulate III／IV、ASBS 与固定新版依赖的兼容，再决定发行版本。三个作品在 App 发行时可运行是硬门槛，兼容失败由用户更新作品后重验。此决定用较小的分发与维护范围替换之前的旧共享版本共存方向；原自动回退旧共享版本方案不再成立。正式采用新版本写回工程引用并更新工程版本，临时试验不自动采用；缺版本不静默替换，安装新 App 不自动改写工程。共享引用扩展自包含工程契约，接收方必须具备所声明的资源；实现与验收尚未交付。当前范围及未决分支见[版本讨论](../plans/pre-v1.7-release-grilling.md)。
