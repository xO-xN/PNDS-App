# 帮助语料以 zh-CN/ 与 en/ 两棵镜像树维护

帮助语料随 App 打包分发，读者包含英文乐手。与其把中文原文留在 docs/ 根、另行挂英文镜像（或构建期机翻），语料整体迁入两棵完整树：`docs/zh-CN/` 与 `docs/en/`，目录名与 i18n 语言码一致。语料契约三处（tauri.conf.json bundle 映射、help.rs 白名单、help-corpus.ts 书册清单）同时登记两棵树，防漂移测试断言两棵树文件集合相等——任一侧缺一份翻译即构建失败，而不是静默回退到另一语言。两棵树的内容级同步靠约定：同一 commit 内一起改。

## Considered Options

- 只双语化 reference/（否决：英文用户打开帮助中心，教程与创作者指南仍是中文，体验断裂）。
- 中文留在 docs/ 根、镜像进 docs/en/（否决：不对称布局让「哪份是正本」永远存疑，漂移更容易发生）。
