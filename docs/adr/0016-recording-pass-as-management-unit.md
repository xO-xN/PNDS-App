# 创作叠录以可含多人的录制轮次为管理单位

状态：2026-11-04 产品决定与整体实施范围已确认，工作区实现已更新，原生声音验收待用户完成。决定过程及诊断证据见[本轮记录](../plans/2026-11-04-performance-recording-debug.md)。

创作者需要沿用同一演奏端逐轮叠录，也可能多人一起录制一轮。因此演奏记录以“录制轮次”作为删除与重录单位，每轮保存该次全部参与者的演奏；新增叠录继承其他轮次，整轮重录只替换所选轮次的全部演奏。创作者无需在 App 内追踪记录演奏者身份，工程页面的乐谱选择序号仍由创作者自行选择，同序号不构成覆盖依据。

这修订了 [ADR-0015](./0015-performance-recording-realtime-audio.md) 中以“某位记录演奏者”为重录单位的决定，保留其演奏信息回放、独立来源及共同时间原则。相比按单人替换，按轮管理减少多人排练时的身份选择，但重录一轮会一起移除该轮其他人的旧演奏，不能只替换其中一人或一个时间片段。旧记录未保存轮次关系，完整保留旧文件，其现有全部演奏作为一轮“已有内容”，不按编号或事件时间猜测原始轮次。
