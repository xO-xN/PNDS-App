# 工程版本本地保存，按当前分支备份到 GitHub

2026-11-11，创作者确认 GitHub 同步首版的交互规则。本地保存独立完成，创作者可以离线继续工作，并明确选择哪些工程与分支备份到 GitHub。

- **入口。** Git 版本页内联显示 GitHub 仓库、当前分支、同步状态和操作。进入该页、手动刷新或执行同步时检查远端，离线时显示上次已知状态。
- **GitHub 授权。** 创作者可在「设置 → GitHub 账号」连接或退出。首次绑定仓库或克隆私有仓库也可按需「连接 GitHub」。创作者在系统浏览器完成 GitHub App 设备授权和仓库访问设置，回到 PNDS 选择仓库。PNDS 在 macOS 钥匙串保存令牌。本地创作与版本保存独立于授权状态。
- **绑定仓库。** 创作者在 GitHub 网页创建仓库，再回到 PNDS 选择已授权仓库。首版允许绑定空仓库或与本机工程共享 Git 历史的仓库。已有的 GitHub `origin` 可预填为候选，创作者确认后才绑定。PNDS 保留外部 Git 的远端和跟踪配置。确认解绑或改绑时取消旧目标的待备份任务，保留本地版本。
- **保存与备份。** 「保存当前版本」默认保存到本机。创作者可手动备份，或主动开启保存后自动备份。首次备份到公开仓库前，明确确认仓库、分支和将公开的已提交历史。
- **分支。** 备份与更新只操作当前分支及其 GitHub 同名分支。新创作分支首次备份时建立同名分支。停在历史版本时，先切回分支或保存成新分支。曾备份的远端分支被删除后暂停自动备份，经创作者确认才重建同名分支。
- **离线重试。** 自动备份因断网未完成时，显示待备份状态。待备份记录随原工程与分支保留，重启后在恢复联网、自动备份仍开启且原工程与分支重新打开时续传。
- **更新工程。** 创作者可主动从 GitHub 更新本地工程。更新要求工作区干净且当前分支可以快进。出现分叉时，创作者用外部 Git 工具处理，再回到 PNDS 继续。
- **克隆工程。** 从「选择工程」选择仓库、分支和本机新目录。克隆通过现有创作工程打开检查后，打开工程并绑定来源仓库，默认手动备份。运行依赖与 SynthDef 仍在创作者主动测试时检查。

本决策扩展 [ADR-0011](./0011-creator-git-version-navigation.md) 的本地版本工作流。应用远端版本沿用既有的草稿、外部暂存、助手任务和运行保护。`.pnds` 的发行由 Agent 与 GitHub Actions 流程处理。
