# 模式切换采用非对称工程接续

状态：已接受；按定稿原型第五轮决策更新，取代本 ADR 原先的双向结束运行方案。

v1.6 引入演出模式与创作模式，两次点击模式按钮完成确认。演出→创作时，以正在运行的工程为准：可编辑文件夹工程直接进入同一工程的创作工作台，保留运行与已应用音频配置；无运行工程时，直接打开已选可编辑文件夹，但不自动启动测试。已安装的 `.pnds` 副本与内置工具不进入编辑，此时结束旧运行并进入创作首页。进入创作时关闭投影窗口。

创作→演出始终结束测试、关闭测试窗口与投影窗口，并回到未加载工程的演出首页；每次启动 App 也从这个首页开始。这样，演出中的可编辑工程无需重复打开和启动，而创作测试状态不会自动带回现场演出。切换前显示未保存修改与关停后果，取消不改变工程或运行；启动和关停尚未完成时不接受新的模式切换。

## Considered Options

- 两个方向都结束运行（已被定稿原型取代：演出中的源工程转入创作时重复打开和启动造成不必要的中断）。
- 两个方向都保留运行（否决：创作测试会被直接带回演出，且已安装工程包与内置工具的副本不能成为编辑源工程）。
