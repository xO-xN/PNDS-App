# 待处理文档使用工程内私有的独立文本文件

2026-10-28 设计核实第二轮确认：以“待处理文档”替换“创作资料”，将每份文档保存为工程专用暂存目录中的独立文本文件，使创作者能够在 App 主编辑器以及 Finder／外部编辑器中访问。暂存区沿用 `.pnds-creation/` 私有创作数据边界，随完整工程目录迁移，接入前排除于工程 Git 版本、默认演出包和工程运行检查。

选择独立文件，是为了使文档具有真实文件的可移植性和外部可访问性；单个 JSON 正文记录不能直接供外部编辑器逐份访问，独立文件则需要原生存储处理文件与元数据的一致性、外部编辑和迁移。采用工程私有边界，是为了让尚未接入的外部代码保持等待状态，直到文件位置、必要入口和引用已明确接入；普通源码目录会使这些文档提前进入版本和演出分发范围。相应地，Git clone 不携带暂存文档，工程版本切换不能承担暂存原文的恢复。

本记录确认存储与分发边界，不表示已实现。接入完成、原文移出、历史来源与撤回恢复的一致性见[已确认方案](../plans/pending-documents-design.md)；这些职责不能依赖已完成后会被清理的助手任务日志。2026-11-03 用户确认工程文档收录规则，并明确要求暂不实施。
