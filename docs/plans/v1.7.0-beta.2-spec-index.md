## 跨项边界

- 端口策略由 #259 统一拥有，池主／池客 #258 使用实际入口、运行身份和已核验端口；两项共同验收端口变化与网页持久数据恢复。
- 演奏记录 #257 由池主或创作模式本机运行的工程负责，池客输入可被工程记录；不向池客增加整场录制控制或 App 托管的声音进程。普通停止录制继续演出；回放／叠加结束只释放相应来源。
- 待处理文档 #260 通过明确工作任务接入工程。私有暂存／恢复边界、工程版本、演奏记录来源和实际运行内容分别表达，不能把文档保存或接入当作运行或音画验收。
- 媒体／Worker／存储、端口协商、录制适配与耐久恢复的具体协议由实施阶段验证后固定，不再开启产品访谈，也不以未验证方案改变已确认行为。

前次规格整理仅包含建票与索引，不自动授权编码；上方实施记录对应后续明确授权。本次没有提交代码或发布 App。历史设计文件保留逐轮决定，原 v1.7.1 文件名仅为维持链接；四份规格与跟踪票继续拥有各自实施范围。
