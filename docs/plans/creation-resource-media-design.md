# 创作资源中的图片与音频

首版产品决定已确认。

## 收件箱与预览

- 文件入箱时复制到当前工程的私有暂存区。副本在重开工程后仍可使用，随包含隐藏目录的完整工程迁移。暂存副本沿用私有创作数据的分发边界，排除于 Git、运行检查和默认 `.pnds`。[现有私有暂存决策](../adr/0012-pending-documents-private-files.md)
- 导入成功后文件先出现在左栏。点选图片查看预览，点选音频后由创作者主动播放。试听覆盖完整录音，提供播放、暂停和进度定位。
- 预览与编辑使用中栏文件标签（原型 A）。图片可放大查看细节。创作资源固定占据左栏底部的一部分，空态保留相同空间并显示收件箱图标和拖入提示。点按标题栏的收件箱图标可选择文件。文件较多时在分组内滚动。
- 新建与导入的文本都可在中栏编辑。编辑后的草稿沿用现有保存流程，助手接入前使用保存版。[待处理文档编辑器](../developer/creation-workspace.md#pending-document-editor-260)
- 试听使用底栏显示的本机输出。当前工程的 Internal 测试运行时，使用实际生效的设备。其余时候使用底栏当前选择。指定设备断开时停止试听并提示。External、None 及工程静音时仍可主动试听，试听单独控制音量。[工程音频行为](../developer/app-behavior.md#音频-host-行为)

## 创作资源接入

- 创作者把图片或音频交给创作助手。助手结合工程现有代码、资源类型和任务用途，选择合适的工程位置，并修改使用该资源的代码或引用。
- 在「工作」任务里可点选资源或用文字指明。用途清楚且能唯一识别文件时，助手可以继续。有多个候选或用途有歧义时先向创作者确认。
- 首版向助手提供文件名、类型、大小、可取得的音频时长或图片尺寸等信息。图片和音频的原始内容留在本机，由 App 按助手确定的位置复制。
- 目标路径已存在且内容完全相同时可复用。内容不同时，请创作者选择「并存」「替换」或「取消」。推荐并存，由助手选择另一个文件名并更新引用。
- 同一次「工作」接入的文档、图片和音频在目标文件与引用全部保存并核对、恢复记录已持久化后，一起移出待用列表。仅查看过的资源继续留在列表。失败或取消时保留所有暂存原件，列出已保存的工程修改，供创作者继续修正或撤回整次工作。
- 静态检查通过且运行检查确实无法执行时，可以记录「已接入，尚未运行验证」并显示原因。实际运行检查失败、取消或结果过期时，接入仍待完成。受控检查结果和实机音画验收分别记录。
- 从工程菜单的「最近一次接入恢复」可以撤回整次接入，或仅将原件放回创作资源。整次撤回校验本次任务写入的文件，删除本次新建的资源，恢复本次替换前的文件，并保留复用的同内容文件。受影响的文件已有较新修改时，保留这些修改，仍可选择仅恢复原件。恢复原件遇到同名冲突时，先保留待用列表里的现有文件。[现有接入与恢复流程](../developer/pending-documents.md#explicit-integration-and-recovery)

## 首版验收

- 用真实「工作」任务验证三条路径。图片作为 performer 背景，音频由页面播放，WAV 由 SuperCollider 加载为采样。核对实际接入路径、修改的引用和运行结果。Blank 的默认服务器当前需要补齐页面音频的文件服务。[Blank 静态文件服务](../../src-tauri/resources/blank-project/server.js)
- 在 macOS 默认设备与 PNDS 底栏设备不同的情况下验证试听路由，覆盖播放中断开设备、切换工程和长录音定位。用实测确定首版支持的格式和容量上限。
