本清单现共 66 张叶子票，包含已完成和待实施／待验收任务。原 58 张的实现和验收成果及第 59–65 项保留；本轮新增工程参数绑定与临时预演基础票，扩写 #166、#167、#168、#171、#208、#172、#224、#225、#226、#229，父规格 #149 及总体规格 #190 同步更新。不改前序版本已确认交付，不关闭或重开 issue。父项正文记录规格，实际任务与依赖以原生子任务和本清单为准。

已有只读 manifest、依赖、路径与打包校验可组成诊断服务，无需新增一张纯后端抽取票。运行检查先贯通一个可验收的 None 工作流，在该票内整理必要运行接缝；不拆数据库／Rust／UI／测试等水平票。

发行仍按已确认版本顺序。普通实施票只保留真实技术前置，移除“共享库必须等 v1.6.0 发行”“Classic／Doctor 必须等三作品发行验收”“Template 必须等整套 Skills 验收”等整版阻塞；各版发行票负责最终放行。v1.7.0 正式开发仍受 #164、#189、#191、#192、#193、#194 六项前序验收门控。助手票经 #165 传递；新增编辑器、Git 与参数预演基础票直接列同一六项门控及真实技术前置，不要求其等待模型配置实现。其他新增票经依赖传递，#172 收口全部能力。

2026-10-12 的草案代号 A–N 已替换为正式 issue 编号；前次新增票已取得 #224–#230，本轮新增参数预演基础票为 #231（第 66 项）；阻塞关系使用 GitHub 原生依赖。表述中的版本固定候选需在实现时重新核对，发行前冻结，模型始终由工程携带。

66. **v1.7.0：提供工程参数绑定与临时预演能力**（[#231](https://github.com/xO-xN/PNDS-App/issues/231)，新增）

    **Blocked by：** #164、#189、#191、#192、#193、#194

    **What it delivers：** 提供独立于模型配置的工程参数绑定与临时预演能力，供讨论建议卡按工程实际能力调用。助手可根据当前讨论与真实代码提出参数控件；App 核对来源、版本、类型和约束，工程以受限接口声明哪些参数能够临时生效。以实际能力决定预演方式，不按画面／声音划分作品范围，不假设所有工程天然适配。

    **验收：**
    - [ ] 参数描述包含当前可信工程、目标文件与来源版本、可定位代码、当前值、类型、工程已有约束及预演能力；模型建议的范围与工程硬限制明确区分。连续数值可用 fader，其他受支持值可用文本、开关、选项或颜色控件；不能准确绑定的内容保留代码编辑或讨论，不伪造可操作参数。
    - [ ] 绑定及能力核验在本地受限服务执行，可由无模型的受控工程独立验证；描述中的工程、文件、来源版本、类型或限制不符时拒绝。工程文件仍受既有可信边界、内容限制与路径校验约束，不因参数描述获得任意读取或写入能力。
    - [ ] 临时预演使用明确版本的工程适配／能力协商及受限消息接口，只允许声明的参数和值；不将模型返回的 JavaScript、表达式或任意代码注入页面执行，不提供任意 shell、进程控制或跨文件写入入口。实现设计需记录描述与适配契约及兼容失败行为。
    - [ ] 已适配参数可以临时作用于当前同一 monitor／工程会话；显示预演对象、支持范围和实际反馈，未适配、需要刷新／重启或只能预演部分变化时明确说明。不能把数值更新、消息发送成功或局部效果冒充完整代码已运行或验收通过。
    - [ ] 数值拖动等即时预演与明确发起的代码预演可复用此能力；建议代码变化后必须撤销旧预演，重新核验能够映射的参数及支持范围，不能逐键执行代码，也不能在无法准确映射时继续显示旧参数对应的新效果。建议卡、编辑 buffer、显式应用与实际差异由 #208 集成。
    - [ ] 临时预演不写工程文件、文件草稿、交接基线或 Git，不自动请求模型、刷新、启停或重启服务及音频；必要运行条件不满足时提示用户按既有流程操作。涉及声音的实时能力同样依据工程明确声明及约束验证，不因支持预演自动开启声音。
    - [ ] 支持结束／恢复预演、取消、失败与连续操作收敛；分别绑定工程、当前运行会话／加载版本、建议修订与文件保存版本。工程切换、停止测试、外部或未经重新核验的来源变化、适配失效或页面重载使旧预演失效，迟到反馈不能污染新工程或较新的预演。工程来源已变时不能用旧快照覆盖新状态。用户明确应用后，仅在原预演绑定重新核验有效时可保留临时预演标记，保存版和实际运行版仍分别表达，采用保存版仍由用户手动刷新／重启。
    - [ ] 结束预演恢复对应的临时参数状态，不承诺回退运行时间或撤回已发生的实际效果；恢复失败明确显示尚未恢复并引导手动处理，不伪称成功或自动重启工程。
    - [ ] 缺少适配时可以提出适配建议；仅一个已有文本文件能够完成的修改仍须经过 #208 的具体应用授权与冲突保护，新建／删除／重命名、跨文件或复杂适配经 #171 handoff。不给普通对话增加隐式安装适配、执行或写入权限。
    - [ ] 以不同参数与组织结构的真实受控工程覆盖：连续数值、非数字值、有效／缺失／不兼容适配、参数硬限制与建议范围、局部支持、源版本变化、快速连续预演、取消、失败、切换及迟到结果隔离；验证实际可观察效果及无文件／Git／进程副作用。工程端参数接口与模型判断分别验收，#172 另以真实模型覆盖应提供、不应提供和应先澄清的情形，不能以固定原型参数代替。
    - [ ] 新增业务逻辑有测试，中英文案、键盘操作、主题和可访问反馈完整；相关工程适配、开发和帮助文档同步，npm run check:all 全绿。真实 App 由用户启动并反馈，自动化不代替实际画面或声音验收；本票不等待模型配置或助手 UI 实现。
