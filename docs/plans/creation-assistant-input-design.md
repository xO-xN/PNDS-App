# 创作助手输入栏

## 已确认

### 文件引用

创作者可以把工程文件树中的可读保存版文本拖入创作助手输入框。沿用[创作资源原型](../prototypes/creation-resource-media.html)的选择器和可移除标签，让拖放和键盘选择进入同一条消息草稿。创作资源里的图片和音频沿用[已确认的媒体规则](./creation-resource-media-design.md)，向助手提供元数据，原件留在本机。未保存文本可通过现有的显式选区附件加入。工程文件拖到 Finder 继续沿用现有复制操作。

### 创作助手技能

输入框以 `@` 加技能名称发起调用。输入 `@` 时只补全当前模式可用的技能。每条消息可调用一项技能，仍可添加文件引用和补充说明。发送后按现有助手请求流程加载对应指令。

首版包含两项内置技能。

| 调用                  | 任务                 | 模式 | 交付                                                                        |
| --------------------- | -------------------- | ---- | --------------------------------------------------------------------------- |
| `@check-unused-files` | 检查疑似未使用的文件 | 讨论 | 核对 manifest、加载入口与资源引用，给出文件路径、判断依据和无法确认的地方。 |
| `@write-readme`       | 制作作品 README      | 工作 | 按现有封面格式制作英文和简体中文根 README，保存后供创作者浏览核实。         |

### 作品 README

英文写入根 `README.md`，简体中文写入根 `README.zh-CN.md`。沿用[经典模板](../../src-tauri/resources/classic-project/source/README.md)和 [README 指南](../zh-CN/readme-guide.md)。顶部是作品标题和独立的 `key: value` 封面字段，首个二级标题及其下的正文用于 App 和开演前投影的作品简介。仓库读者需要的扩展说明可以放在 `---` 之后。两份文件使用相同的已核实作品事实，已有署名、封面设置和后续章节按任务范围保留，缺失资料列在交付回复中。

如果工程已有 `README.en.md`，写入前先请创作者确认如何处理。英文界面优先读取该文件，即使已经生成英文 `README.md`。简体中文界面优先读取 `README.zh-CN.md`。

验收时用实际保存的两个路径打开现有创作预览，检查作品标题、封面字段和首节简介。再切换 App 语言，核对主窗口和开演前投影实际读取的文件。经典模板的两个文件已通过现有封面解析。Blank 当前会按创建时的界面语言生成一个根 `README.md`，双语产物约定适用于制作 README 技能。
