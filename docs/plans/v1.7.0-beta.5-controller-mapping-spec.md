# v1.7.0-beta.5 · MIDI／OSC 控制器映射

## Problem Statement

演奏者希望用已有按钮、推子和旋钮控制当前工程，并在演出准备时快速完成绑定。现在每个工程需要自行接入外设，既有的 MIDI／OSC 工程能力也没有为所有工程页提供共同的映射入口。池主操作 monitor 页，池客操作自己加入演出后打开的 performer 页。两种角色都需要在各自的 Mac 上使用控制器。

旧工程包含按标准网页事件工作的控件，也包含画布内自绘的控件。前者适合直接学习，后者需要工程开放可调用的参数或动作。映射还要支持演奏者为每个目标设定独立的数值范围，使实体推子可以只扫过工程参数中的一段。

## Solution

v1.7.0-beta.5 在设置的「演出」中新增「MIDI／OSC 控制」，管理输入设备、OSC 来源和完整的映射列表。从演出或创作的底栏一键进入映射模式，点选当前工程页的控件，再操作硬件学习输入。控件原位显示已绑定的地址。退出映射模式后，外设通过工程原有的控件逻辑触发动作或改变参数。

池主的 monitor、池客保留的 performer 页和创作测试的主 Monitor 共用这套操作。同一工程在池主与创作使用同一套映射。旧工程的标准网页控件可直接参与，工程可以开放自绘控件的映射目标。画面位置选填，只有动作的目标可以在工程打开时从设置选择。映射按本机、工程和演出角色保存。

## User Stories

1. 作为池主，我希望直接在 monitor 页学习外设映射，以便用实体控件操作工程。
2. 作为池客，我希望在已加入演出的 performer 页使用同样的流程，以便在自己的 Mac 上使用控制器。
3. 作为准备设备的演奏者，我希望在「演出」设置下找到「MIDI／OSC 控制」，以便在加载工程前完成接线。
4. 作为 MIDI 控制器用户，我希望查看并启用具体输入端口，以便选对要用于映射的设备。
5. 作为正在接线的演奏者，我希望看到启用来源最近收到的消息，以便核对端口、通道、CC、Note 或 OSC 地址。
6. 作为在同一台 Mac 上运行 OSC 软件的演奏者，我希望默认使用本机 OSC 接收，以便在本地学习和控制。
7. 作为使用局域网 OSC 控制器的演奏者，我希望显式启用局域网接收并配置来源，以便接入场地里的设备。
8. 作为使用多台 OSC 设备的演奏者，我希望相同 OSC 地址可按发送方区分，以便沿用各设备的布局。
9. 作为正在准备演出的用户，我希望从底栏一键进入映射模式，以便直接在工程画面上找目标。
10. 作为已经进入映射模式的用户，我希望点击工程控件来选取目标，以便点下按钮时专注于建立绑定。
11. 作为使用 MIDI 推子的用户，我希望移动推子即可学到其绝对 CC，以便免手填消息号。
12. 作为使用 MIDI 键或打击垫的用户，我希望按下一次即可学到 Note，以便控制工程中的按钮或开关。
13. 作为使用 OSC 的用户，我希望通过单个数值或只有地址的触发消息完成学习，以便复用现有控制器。
14. 作为需要连续绑定多个控件的演奏者，我希望学到一条就看到地址并保存可持久化的映射，以便继续点选下一个目标。
15. 作为在画面上检查绑定的演奏者，我希望看到地址贴在相应控件上，以便辨认各个目标。
16. 作为已经完成接线的演奏者，我希望再点底栏按钮或按 Esc 退出映射模式，以便开始使用已学习的映射。
17. 作为临时取消的演奏者，我希望退出时结束当前未完成的学习，以便保留此前已经学好的映射。
18. 作为现场改绑的演奏者，我希望用原输入学习到新目标时自动替换旧映射，以便快速调整控制布局。
19. 作为更换目标输入的演奏者，我希望给同一控件学习新输入时自动替换旧输入，以便该控件的地址与实际控制一致。
20. 作为使用既有工程的演奏者，我希望可识别的标准网页按钮、开关与推子可以直接映射，以便使用原版工程。
21. 作为使用旧工程的演奏者，我希望可以临时绑定当前能点选而无法可靠重定位的控件，以便当次演出仍能使用外设。
22. 作为在演出中重载页面的演奏者，我希望旧控件被替换时临时映射随之失效，以便重新明确选择目标。
23. 作为工程创作者，我希望能以稳定身份开放已有的参数或动作，以便自绘控件也能接入。
24. 作为使用自绘控件的演奏者，我希望能在工程提供的位置直接点选并看到映射标签，以便沿用网页控件的操作方式。
25. 作为使用已开放动作的工程的演奏者，我希望可在设置选择没有画面位置的目标，以便控制这些参数或动作。
26. 作为检查整套控制布局的演奏者，我希望在设置查看完整映射列表，以便核对目标、来源和当前配置。
27. 作为正在管理本机配置的演奏者，我希望列表默认显示当前工程和角色，并能切到曾保存过映射的工程，以便在准备时整理配置。
28. 作为修改映射的演奏者，我希望可以删除条目，以便立即撤掉已不使用的绑定。
29. 作为重新打开同一工程的演奏者，我希望恢复该工程和角色已保存的映射，以便继续既有演出准备。
30. 作为同时使用多个工程副本或不同池主的演奏者，我希望它们各自保存绑定，以便控制器按实际工程与页面工作。
31. 作为用推子控制混响的演奏者，我希望给每条映射设置目标最小值和最大值，以便用整个推子行程控制例如 20%–80% 的混响量。
32. 作为使用方向相反的硬件的演奏者，我希望独立反向一条映射，以便物理动作符合我的演奏习惯。
33. 作为使用自定义 OSC 数值范围的演奏者，我希望调整该输入的范围，以便正确映射 0–100 等取值。
34. 作为控制有步进的参数的演奏者，我希望换算后的值遵守工程的合法步进，以便参数达到我能从页面选择的值。
35. 作为使用绝对 MIDI 推子的演奏者，我希望推子接近或经过页面当前值才接管，以便避免一动推子就跳到实体位置。
36. 作为缩窄参数范围的演奏者，我希望页面当前值在范围外时能从最近端点接管，以便在设定范围内继续操作。
37. 作为用 OSC 直接设置参数的演奏者，我希望数值消息按配置立即生效，以便执行明确的目标设置。
38. 作为用按键触发动作的演奏者，我希望一次按下只触发一次，以便每次触发都对应一次按下。
39. 作为使用工程开关的演奏者，我希望外设通过工程原有的操作改变状态，以便页面和工程运行结果一致。
40. 作为同时操作其他软件的演奏者，我希望 PNDS 失焦、隐藏或最小化后仍能通过映射操作当前保留的工程页，以便维持演出。
41. 作为暂时失联的池客，我希望外设仍能控制保留页上的本地操作，以便使用工程支持的断线继续演奏能力。
42. 作为仍在操作保留页的池客，我希望池主停演或发现另一场演出后，外设仍指向我当前的页面，以便自行决定何时离开或切换。
43. 作为离开或更换工程的演奏者，我希望旧页的输入投递随页面归属结束，以便控制器作用于我确实打开的页面。
44. 作为使用工程共享状态或演奏记录的演奏者，我希望映射沿用工程的现有控件处理逻辑，以便原有的同步和记录规则继续适用。
45. 作为在创作中测试工程的用户，我希望直接在主 Monitor 学习映射，并复用同一工程的池主映射，以便在工作台验证实际输入。

## Implementation Decisions

- **底栏入口。** 将设备和完整映射列表放在「设置 → 演出 → MIDI／OSC 控制」。演出和创作的底栏都提供进出映射模式的按钮，当前工程页就绪时可进入。映射模式内的 Esc 退出模式，工程页沿用已有快捷键约定。
- **设备接入。** macOS 原生层接收 Core MIDI 和 UDP OSC。MIDI 来源以输入端口、通道和消息身份识别。OSC 来源配置包含接收端口，默认接收本机消息，局域网接收由操作者显式开启并按发送方和地址匹配。启用来源可显示接收活动。入站控制独立于工程音频模式与现有的出站 OSC 音频目标。
- **首版消息及动作。** 支持 MIDI Note、7 位绝对 CC、单个数值的 OSC 消息和无参数 OSC 触发。支持连续量、开关与单次触发。一次按下只触发一次，松开为下一次按下复位。一个无参数 OSC 事件表示一次触发。
- **学习与改绑。** 在当前工程页识别和点选目标。映射模式内页面点选用于学习，匹配的设备输入完成绑定、更新标签并立即保存可持久化的映射。待完成的学习随退出结束。同一入口信号和同一目标各保留一条映射，新学习自动替换冲突的旧映射。退出后按当前绑定投递演奏动作。
- **标准与自绘目标。** 对可识别且能走现有标准网页事件的控件提供免改工程的接入。自绘目标由工程明确开放稳定 ID、名称、控件类型和可调用动作。连续目标提供合法范围、步进及读写当前值的能力。根据 ADR-0027，画面位置选填，提供位置时支持原位点选和显示地址，其余已开放目标在工程打开后可从设置选择。
- **定位与临时映射。** 持久化目标须有稳定 ID 或可在同一工程页中唯一重定位的控件身份。只能在当前控件实例上确认的目标可以临时映射。控件重建、刷新或离开时清除该临时绑定。已保存目标消失或匹配有歧义时标为待重新绑定，并停止投递到该目标。
- **本机所有权。** 根据 ADR-0026，使用现有偏好保存机制按实际工程和演出角色持久化。池客从已确认的池主与工程确定归属，保存身份与当次演出的页面投递归属分别处理。另装副本、其他池主和其他 Mac 各自建立映射。设置默认定位当前工程和角色，也能查看、删除、调整以前保存的条目，学习需要打开对应工程。
- **范围换算。** 连续映射显示输入区间，并提供独立的目标最小值、目标最大值和反向。7 位绝对 CC 使用 0–127，单值 OSC 的输入默认 0–1 并可调整。目标区间默认采用工程参数的有效范围，可收窄为其中一段。按比例线性换算，输入越界时取最近端点，结果服从目标区间与工程步进。反向交换输入两端对应的目标值。
- **软接管。** 绝对 MIDI 推子比较换算后的目标值与页面当前读值，接近或经过当前值后开始驱动。若当前值在映射范围外，以最近的范围端点作为接管位置。OSC 数值按配置直接更新目标。
- **投递与生命周期。** 共享映射规则通过已受管的两个 WKWebView 呈现入口投递给当前页面。工程页接收已绑定的动作或值，并沿用原有控件处理与角色权限。切换 App、隐藏或最小化时保留当前页的映射。池客断线或池主停演时仍可操作保留页的本地控件。网络操作沿用 ADR-0017 的参与入口和工程原有规则。离开、刷新或成功切换时撤销旧页投递归属；迟到的输入不能改投新页。
- **创作测试。** 主 Monitor 与池主共用同一工程的映射。演出接手到创作并保留同一运行和文档时，保留映射模式和文档令牌。创作重启后旧令牌失效，新 Monitor 按工程身份恢复已保存的映射。
- **工程与 App 接口。** 沿现有类型化命令和偏好队列处理设备选择、学习状态与映射管理。页面使用窄接口注册和应用目标。连续控制经原生层与页面桥投递，界面订阅设备和映射的显示状态。工程继续借由它已有的处理器应用共享状态、演奏记录和声音。采用现有的双语文案、焦点、底栏与原生页面规则。

## Testing Decisions

- **主要验收入口。** 用户已确认从应用设置及实际演出页走完整的学习和控制流程。自动化通过正常的设置命令、加载和加入操作创建池主与池客页面，在原生设备入口提供可控输入，然后观察工程动作、实际值、页面标记和本机恢复结果。这一流程覆盖实现所使用的页面投递与绑定路径，保留原生 AppShell 和真实池客加入的集成夹具作为先例。
- **覆盖池主与池客。** 用旧工程的池主 monitor 标准按钮及池客 performer 标准推子核对点选、学习、原位标记、退出、实际控制和重开恢复。验证按键／设备消息的学习归属、Esc、自动改绑两端冲突、临时映射失效、待重新绑定、设置中切换已保存工程和删除。可用 Runes 的演奏模式按钮和 Nameless Nightmare 的推子作为样本。
- **覆盖自绘目标。** 用受控工程检验已声明目标有画面位置时的原位点选和标记、无画面位置时的设置入口、页面控件重建，以及重定位时对同一工程目标的准确识别。原生画面与键鼠判据沿用现有 AppShell、原生工程页面的验收方式。
- **覆盖输入与数值。** 用可控 MIDI 消息和真实回环 OSC 数据报核对启用状态、消息类型、按钮触发、输入来源与相同 OSC 地址的区分。验证 0–127 映射到 20%–80% 的两端、中间值、反向和步进，调整 OSC 输入范围后测试越界，测试 MIDI 软接管、范围外最近位置及 OSC 立即更新。对难以在界面复现的数值边界补充小范围业务测试。
- **覆盖页面接续。** 沿用池客原生加入及断线接续夹具，验证当前页面在断线、原演出停演和发现新候选之后仍可处理本地映射。成功换页、刷新或离开后，旧输入停止投递，同一场重新接续时保留当前页，工程原有网络准入仍生效。
- **覆盖创作测试。** 从正在学习的池主页面接手同一运行进入创作，核对原文档和映射模式保留。在创作主 Monitor 学习或触发映射，重启测试后确认新文档恢复已保存的映射。
- **独立的 macOS 实机证据。** 通过实际 MIDI 控制器与局域网 OSC 设备在安装应用上核对枚举、学习和响应。验证池主与池客、切到其他 App、隐藏或最小化后的响应，记录 macOS 版本、架构、设备、工程、操作和实际观察。覆盖仓库发布的 arm64 与 x86_64，分别记录尚待核验的组合。协议输入模拟与原生夹具的结果单独记录。
- **完成标准。** 新业务逻辑带测试，npm run check:all 全绿，演出入口和实机结果写入 beta.5 验收。采用现有独立原生夹具和受管测试工程，开发服务器按仓库既定方式由用户启动。

## Out of Scope

- 相对编码器、高精度 MIDI、MIDI Clock、控制器 LED 或电动推子回传。
- 按住和松开分别执行动作的控制、多目标联动、采样级实时控制。
- 跨 Mac、池主或安装副本交换映射配置，或把操作者设备绑定写入工程包。
- 用坐标回放自动操作未开放动作的旧画布，或批量改造旧工程。
- 在投影窗口、普通浏览器演奏端、独立创作 performer 测试窗口和 App 管理控件上直接学习映射，以及独立的暂停外控按钮。

## Further Notes

这是 v1.7.0-beta.5 的控制器映射规格。发布验收记录实际演出页、创作主 Monitor、可用硬件和安装构建的结果。首版可用的旧工程标准控件与需要额外接入的自绘目标分开验证。自绘控件复用已有演奏动作和参数，提供画面位置后即可在原位点选与显示地址。
