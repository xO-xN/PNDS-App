# PNDS v1.7.0-beta.3

预发行测试版，适用于 macOS 13.5 及以上。Apple Silicon Mac 下载 `_aarch64.dmg`，Intel Mac 下载 `_x64.dmg`。

## 主要更新

- **GitHub 同步。** 在创作模式的「Git 版本」页绑定仓库、备份已提交的版本，或从同名分支更新。也可在打开工程时克隆到新目录，在另一台 Mac 上继续创作。默认手动备份，可开启保存后自动备份。请先连接 GitHub 账号并为目标仓库授予访问权限。 [GitHub 同步指南](https://github.com/xO-xN/PNDS-App/blob/v1.7.0-beta.3/docs/zh-CN/app-tutorial.md#github-%E5%90%8C%E6%AD%A5)
- **统一演奏入口。** 浏览器和原生 PNDS 池客使用同一个池主入口。地址、复制与二维码集中在底栏网络弹层。同一入口可发现下一场演出，演奏者确认后进入。暂时失联或切换失败时保留已打开的谱面。未适配的工程仍可使用其原有接入方式。
- **新建工程与原生媒体。** 新工程统一从 Blank 开始，提供身份恢复、共享视图、鼠标及触控基础。既有 Classic 工程仍可打开。支持的工程可以在原生 monitor 和演奏者窗口使用设备媒体，并按需接入运动传感、麦克风及离线 HandPose。
- **演奏记录与测试。** 支持多轮录制、回放、叠加排练与整轮重录，可导入和导出 `.pndsrecord`。创作测试增加内部音频频谱和连接演奏设备的入口。支持自动运行端口的工程可避开端口冲突。
- **创作工作台。** 整合本地 Git 版本与历史、待处理文档，以及创作助手的讨论、明确编辑任务、受控检查与外部交接。使用创作助手前请在设置中配置模型服务。

## 安装与反馈

安装前退出 PNDS，保留旧安装包，并备份完整工程目录及隐藏文件（含 `.git` 和 `.pnds-creation`），同时备份 `~/Library/Application Support/com.xo-xn.pnds-app/`。beta 与正式版共享此数据目录。需要返回旧版时，先保留 beta 期间的新内容，再从测试前的副本恢复。

安装包采用 ad hoc 签名。双架构安装、真实双机演奏及断公网浏览器接入的结果请记录到验收票。反馈时请附完整 App 版本、Mac 架构、macOS、工程类型和复现步骤，并先对日志脱敏。 [浏览器验收 #313](https://github.com/xO-xN/PNDS-App/issues/313) · [安装验收 #314](https://github.com/xO-xN/PNDS-App/issues/314)

后续 beta 从 Releases 页面手动下载。App 的更新检查继续使用正式版通道。 [PNDS Releases](https://github.com/xO-xN/PNDS-App/releases)

## English

This prerelease supports macOS 13.5 and later. Download `_aarch64.dmg` for Apple Silicon or `_x64.dmg` for Intel.

### Highlights

- **GitHub sync.** Bind a repository from **Git versions** in creation mode, back up committed versions, or update from the branch with the same name on GitHub. You can also clone a project into a new folder to continue on another Mac. Backups are manual by default, with an option to back up after saving a version. Connect your GitHub account and grant the app access to the target repository first. [GitHub sync guide](https://github.com/xO-xN/PNDS-App/blob/v1.7.0-beta.3/docs/en/app-tutorial.md#github-sync)
- **Shared performance entry.** Browsers and the native PNDS Client use the same Host entry. Find the address, copy control, and QR code in the bottom network panel. Performers can discover and explicitly join the next performance from that entry. A temporary disconnection or failed switch keeps the open score available. Projects without shared-entry support can still use their existing entry paths.
- **New projects and native media.** New projects start from Blank, with identity recovery, shared views, and mouse and touch input. Existing Classic projects still open. Compatible projects can use device media in native monitor and performer windows and add motion sensing, microphone input, or offline HandPose.
- **Performance recording and testing.** Record multiple takes, play them back, overdub, or replace a take. Import and export `.pndsrecord` files. Creation testing includes an internal audio spectrum and controls for connecting performer devices. Projects that support automatic runtime ports can avoid port conflicts.
- **Creation workspace.** Local Git versions and history work alongside pending documents and the creation assistant's discussion, explicit edits, controlled checks, and external handoffs. Configure a model service in Settings before using the assistant.

### Installation and feedback

Quit PNDS before installing. Keep your previous installer and back up complete project folders, including hidden files such as `.git` and `.pnds-creation`, and `~/Library/Application Support/com.xo-xn.pnds-app/`. The beta shares this data directory with the stable version. To return to an older version, preserve work created during the beta and restore from the pre-beta copies.

Installers use ad hoc signing. Record native installation on both architectures, two-Mac performances, and browser entry without internet access in the acceptance issues. Include the full App version, Mac architecture, macOS version, project type, and steps to reproduce. Redact logs before sharing. [Browser acceptance #313](https://github.com/xO-xN/PNDS-App/issues/313) · [Installer acceptance #314](https://github.com/xO-xN/PNDS-App/issues/314)

Download future betas manually from the Releases page. The App continues to check the stable update channel. [PNDS Releases](https://github.com/xO-xN/PNDS-App/releases)
