# PNDS v1.7.0-beta.2

本轮提供 Apple Silicon（`_aarch64.dmg`）与 Intel（`_x64.dmg`）本地候选包，
最低系统为 macOS 13.5。实际安装、声音、媒体权限及双机接入由实机测试确认。

## 本轮测试范围

- 演奏记录、回放与创作叠加排练：同一演奏端反复录制、多人同轮演奏、整轮重录、
  单轮及整份删除、记录导入／导出与旧记录兼容。
- 池主／池客：本地演出接入、内嵌原生谱面、稳定来源的网页数据恢复、连接状态、
  刷新／离开／切换角色后的资源释放。
- 自动运行端口：支持工程的端口分配与冲突避让、实际入口地址及旧工程兼容。
- 待处理文档：独立编辑与保存、旧资料迁移、助手按需读取、整任务接入与持久撤回。
- 界面与操作反馈：侧栏入口、角色切换、工程打开、编译及交接反馈等细调。

逐项测试见[演奏记录与池客清单](../acceptance/257-258-recording-and-participation.md)、
[自动端口与待处理文档清单](../acceptance/259-260-runtime-ports-and-pending-documents.md)。
自动化检查与交叉编译不代替 Apple Silicon／Intel 原生验收。

## 安装与后续 beta

本版本沿用现有 App 名称、标识与数据目录。测试前退出 PNDS，保留旧安装包，
备份完整工程（包括隐藏文件）与 `~/Library/Application Support/com.xo-xn.pnds-app/`，
使用工程副本测试。恢复旧版时使用测试前的数据副本。

本地候选包采用 ad hoc 签名，尚无 Developer ID 签名或 Apple 公证。
本轮本地打包不创建 Git tag 或 GitHub Release；后续若发布，应为 Pre-release，
不成为 Latest。App 继续检查正式版更新地址，后续 beta 需手动获取。
