# PNDS v1.7.0-beta.4

这是 1.7.0 的预发行候选。以下列出相对 beta.3 标签的主要新增内容；beta.3 的创作工作台、工程运行、原生媒体及演出能力也包含在本候选中。当前入口与操作见[使用教程](https://github.com/xO-xN/PNDS-App/blob/v1.7.0-beta.4/docs/zh-CN/app-tutorial.md) · [完整代码变更](https://github.com/xO-xN/PNDS-App/compare/v1.7.0-beta.3...v1.7.0-beta.4)

## 本次更新

- **新建工程与 GitHub。** 新建表单集中显示本机位置、仓库目标及可见性，支持公开、私有或仅本机。从官方 Blank 模板创建仓库，首次上传中断后可继续原操作，期间新保存的版本和草稿留在本机。已有本机工程也可核对当前路线与历史后首次上传。自动备份按路线开启，新路线默认保存在本机。
- **版本历史与合并。** 在版本历史内保存当前版本、改名、查看版本树和文件差异，切换路线或从旧版本继续。合并先生成独立候选，可审阅文本、图片和音频差异，处理冲突，并使用候选专属助手、检查及运行测试。明确完成后才写回工程，未完成的候选可保留并继续。
- **创作资源与助手。** 收件箱支持文本、图片和音频。图片可预览，音频可通过所选输出试听；采用媒体前可审阅改动。保存版文件可拖入助手，并附加文件引用与 `@` 技能。新增只读文件盘点及双语 README 工作流，讨论回复和方案随实际模型流显示。
- **工作台与聊天。** 新增创作首页与最近工程列表，控制台改为独立窗口。聊天历史支持搜索、改名和删除。文件筛选集中到侧栏，版本页同时显示版本树与所选文件的差异。
- **演出、录制与设置。** 可在局域网发现 PNDS 节点，审阅工程后加入演出。侧栏支持双指切换工程文件夹。录制弹窗简化列表、轮次管理及导入操作，支持拖入记录。设置按用途重新整理，可逐项显示或隐藏底栏功能入口。

## 安装、兼容性与反馈

需要 macOS 13.5 或更新版本。Apple Silicon（M 系列）Mac 选择 `_aarch64.dmg`，Intel Mac 选择 `_x64.dmg`。安装包采用 ad hoc 签名，未使用 Developer ID 签名或 Apple 公证。beta 从 Releases 手动下载，App 的更新检查仍使用正式版通道。

安装前退出 PNDS，保留旧安装包，备份完整工程目录（含隐藏的 `.git`、`.pnds-creation` 等文件）及 `~/Library/Application Support/com.xo-xn.pnds-app/`。beta 与正式版共享数据目录。演出 `.pnds` 包和 Git 备份不包含全部私有创作数据；完整备份请复制工程目录。返回旧版前先保存 beta 期间的新内容，再使用测试前的副本恢复。

This is a 1.7.0 prerelease candidate. The following changes are relative to the beta.3 tag. It also includes beta.3's creation workspace, runtime, native media, and performance capabilities. See the current [user guide](https://github.com/xO-xN/PNDS-App/blob/v1.7.0-beta.4/docs/en/app-tutorial.md) for entry points and operations. ### Changes

- **Project creation and GitHub.** Review the local location, repository, and visibility in one form. Choose public, private, or local only. Create a repository from the official Blank template and resume an interrupted initial upload while keeping later versions and drafts local. Existing local projects can review their current route and history before their first upload. Enable automatic backup per route; new routes remain local by default.
- **Version history and merging.** Save and rename project versions, inspect the version tree and file differences, switch routes, or continue from an older version. A merge first creates an isolated candidate. Review text, image, and audio differences, resolve conflicts, and use candidate-specific assistance, checks, and runtime tests. Only explicit completion writes the result back to the project. Unfinished candidates can be retained and resumed.
- **Creation resources and assistant.** The inbox supports text, images, and audio. Preview images, audition audio through the selected output, and review media adoption. Drag saved files into the assistant and attach file references and `@` skills. Added read-only file inventory and bilingual README workflows. Discussion replies and proposals follow the actual model stream.
- **Workspace and chats.** Added a creation home and recent projects. The console now opens in its own window. Search, rename, and delete chats. Filter files from the sidebar and keep the version tree visible alongside the selected file's differences.
- **Performance, recordings, and settings.** Discover PNDS nodes on the LAN and review a project before joining. Swipe between project folders with two fingers. The recording panel simplifies lists, takes, and imports, including drag-and-drop import. Settings are reorganized by purpose, with individual visibility controls for bottom-bar entries.

### Installation, compatibility, and feedback

Requires macOS 13.5 or later. Choose `_aarch64.dmg` for Apple Silicon or `_x64.dmg` for Intel. Installers use ad hoc signing without Developer ID signing or Apple notarization. Download betas manually from Releases; the app checks the stable update channel.

Quit PNDS before installing. Keep the previous installer and back up complete project folders, including hidden `.git` and `.pnds-creation` directories, plus `~/Library/Application Support/com.xo-xn.pnds-app/`. The beta shares data with the stable app. Performance `.pnds` exports and Git backups omit some private creation data; copy complete project folders for recovery. Preserve new beta work before returning to an older version and restore from pre-beta copies.

Include the app version, Mac architecture, macOS version, project type, reproduction steps, and actual results in feedback. Redact logs and screenshots.
