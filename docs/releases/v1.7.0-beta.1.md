# PNDS v1.7.0-beta.1

**候选发行说明：尚未发布，尚未通过 [#255 beta 准入验收](https://github.com/xO-xN/PNDS-App/issues/255)。**
本文件用于准备测试版本，不表示安装包、真实模型或设备验收已经通过。
正式 1.7.0 的完整验收继续由 [#172](https://github.com/xO-xN/PNDS-App/issues/172) 收口。

## 本轮测试范围

面向 macOS 13.5 及以上的 Apple Silicon 与 Intel Mac，计划分别提供
`_aarch64.dmg` 与 `_x64.dmg`。请使用与本机架构匹配的安装包；两架构的实际
安装结果和最终产物标识将在 #255 记录。

- 创作工作区：Blank／Classic 新建、文件编辑与显式保存、工程检查、手动运行、
  本地 Git 版本记录及历史载入草稿。
- 创作助手：模型服务设置、只读讨论、逐题回答、按需读取源码与文本资料、
  明确编辑任务下的多文件修改、检查修复与撤回。模型服务需用户自行配置。
- 完整创作流程：资料接入及同名冲突选择、按规范整理工程、讨论中的手动交接与
  基线比较、在本机 SuperCollider 打开已保存 SCD。参数预演取决于工程实际能力。
- 既有演出流程：None／Internal／External、monitor、投影及 performer 的运行
  与退出回归，以及中文／英文界面和帮助检索。

以上是测试目标，不是逐项通过结论。当前尚缺最终安装产物的双架构及干净环境证据，
真实模型对不同作品的判断、资料适配／整理后的画面与声音保真、完整键盘／输入法／
主题／窗口矩阵和真实设备回归也仍需记录。自动化通过不代替这些结果。

## 安装、备份与返回旧版

本轮沿用正式版的 PNDS App 名称、标识和数据位置，没有独立的 beta 数据空间。
安装到同一位置会替换现有 App；改名保留两个 App 也不会隔离它们的数据。
建议仅用工程副本参加测试，暂不用于正式演出。

安装前退出 PNDS，备份完整源工程目录，包括隐藏的 `.git`、`.pnds-creation`
及其他隐藏文件，并备份 `~/Library/Application Support/com.xo-xn.pnds-app/`。
普通 `.pnds` 演出包不包含私有聊天和创作资料，不能代替完整备份。
保留测试前的 App 安装包和数据副本。重新安装旧版不代表旧版能够读取 beta 写入的
所有数据；需要恢复时先保留 beta 期间的新内容，再使用测试前副本，不假定可直接降级。

当前 macOS 构建采用 **ad hoc 签名**，没有 Developer ID 签名或 Apple 公证。
更新产物的 `.sig` 是独立的 updater 签名，不等于 Apple 安装认可。干净 Mac 上的
实际 Gatekeeper 提示、安装和首次启动尚需 #255 验证；本候选说明不承诺可直接安装，
也不提供关闭系统安全机制的步骤。

预期与实际结果，以及是否影响保存、恢复或既有演出。附截图和日志前先脱敏，
不要公开 API key、完整私人聊天或未获许可的作品资料。未执行项目请标为未测。

## English

**Candidate notes: unpublished and not yet admitted for beta testing under
[#255](https://github.com/xO-xN/PNDS-App/issues/255).** These notes do not certify
installation, model quality or device behavior. Full 1.7.0 acceptance remains
open in [#172](https://github.com/xO-xN/PNDS-App/issues/172).

The intended installers target Apple Silicon (`_aarch64.dmg`) and Intel
(`_x64.dmg`), both on macOS 13.5+. Test creation and saved-file editing, local Git
versions and history drafts, configured model services, read-only discussion,
explicit multi-file edit tasks, text material adoption, project organization,
manual handoff and comparison, and opening saved SCD files in SuperCollider.
Parameter previews depend on the project's actual capabilities. Existing
performance modes, monitor/projection/performer windows, both interface
languages and help search also need regression coverage.

The final installers still need native acceptance on both architectures and
clean environments. Real model decisions, preservation of artwork behavior and
sound, keyboard/input-method/theme/window coverage and physical device tests
remain unverified. Automated tests do not establish these results.

This beta shares the stable App's name, identifier and data. Installing in the
same location replaces the existing App; renaming an App copy does not isolate
its data. Quit PNDS before installation and back up complete source project
folders, including hidden `.git`, `.pnds-creation` and other hidden files, plus
`~/Library/Application Support/com.xo-xn.pnds-app/`. A performance `.pnds` export
excludes private chats and creation materials. Keep the previous installer and
pre-beta data; reinstalling an older binary does not guarantee it can read data
written by this beta. Preserve new beta work before recovering from the original
copies. Use disposable project copies for testing and keep this beta out of live
performances.

Current builds use **ad hoc macOS signing**, without Developer ID signing or
Apple notarization. Updater `.sig` files are separate signatures and do not prove
Gatekeeper acceptance. Clean-machine prompts, installation and first launch
still require #255 evidence; these candidate notes do not certify installation
or instruct testers to disable system security.

When published, this version must be a GitHub Pre-release and must not become
Latest. The stable update endpoint remains unchanged. This beta checks that same
stable endpoint, so subsequent betas require manual download from the
[Releases page](https://github.com/xO-xN/PNDS-App/releases). A published
prerelease in this public repository is publicly visible, not a private test
distribution.

Report results in [#255](https://github.com/xO-xN/PNDS-App/issues/255), including
the complete App version/build, Mac architecture, macOS, model service/model,
project type, reproduction steps, expected/actual behavior and any impact on
saving, recovery or an existing performance. Redact logs and screenshots; never
post API keys, complete private chats or artwork materials without permission.
Mark unexecuted cases as untested.
