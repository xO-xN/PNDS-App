# App 产品行为规范

本文定义当前 App 的行为与验收范围。工程接口见[参考手册](../zh-CN/reference/README.md)，操作者步骤见[使用教程](../zh-CN/app-tutorial.md)。

## 产品定位

演出模式下，池主运行本地工程，池客加入另一池主。池客从已确认的演出取得网络授权，已加载页面由自己的生命周期管理。创作模式管理可编辑工程、助手与手动测试。[演出角色](./performance-participation.md) · [池客页面接续](./native-client-continuity.md)

### 创作阅读与模式接续

共用底栏的模式按钮需要两次点击确认。进入创作时，运行中的可编辑工程优先于选中卡，保留已应用配置与 monitor 实例并关闭投影。空闲时直接打开已选的可编辑工程。只读工程或无目标时结束旧运行并打开创作首页。返回演出结束测试并回到空闲 Home。取消保留原工程、草稿和运行。[模式接续](../adr/0007-mode-switch-ends-performance.md) · [工作台](./creation-workspace.md)

模式切换等待确认时，演出底栏的工程按钮保留当前动作名称并暂停提交。启动和停止提示随工程运行操作显示。

当前可编辑工程的唯一终端在同区切页、展开 monitor 和隐藏窗口时保留。切工程、实际替换版本、进入合并候选、离开创作或退出前，先取得结束批准；取消或结束未确认时保留原工作区与草稿，不先保存、退休任务或停止运行。结束只覆盖终端的受管作业，已保存修改保留，CLI 自行脱离终端的后台任务需在 CLI 内完成或取消。[终端离开保护](./project-terminal.md#离开当前工程与退出355)

通用设置的底栏图标预览可逐项显示或隐藏功能入口，加载／运行与模式切换两端始终保留。选择即时生效、跨重启恢复，功能继续遵守当前模式与角色的可用条件。隐藏入口不会停止录制、静音或关闭投影／控制台；设置菜单与 ⌘, 不随设置图标隐藏。

### 固定起点与工程创建

新建工程使用 Blank，生成独立身份和初始版本。目录完整发布后进入创作并登记在演出 Home，运行由用户启动。取消、同名冲突、权限或共享依赖失败保留旧工作区。发布成功但打开失败时显示已创建目录。[Blank 创建](./creation-workspace.md#blank-project-creation)

### 手动保存、重命名与磁盘版本冲突

可编辑文件夹支持新建文本文件、阅读、搜索和草稿。保存和重命名核对实际工程与磁盘版本，冲突时保留草稿。manifest 表单和文本视图共用一份草稿，保留未知字段。合法声明可先保存，完整运行和打包分别预检。工程包和内置工具只读。只有保存版进入测试或打包。[工作台](./creation-workspace.md) · [manifest](../zh-CN/reference/manifest.md)

### 外部修改与磁盘／运行版本

外部文件变化更新文件树。编辑中保留草稿并标记冲突，外部删除同样保留草稿。页面变更提示刷新，服务及音频变更提示重启，SCD 变更提示编译。操作完成只清除当次成功加载或编译的提示。文件动作可把已保存 SCD 交给本机 SuperCollider 打开，编译与启动由各自操作完成。[工作台](./creation-workspace.md)

### 创作手动测试、monitor 与控制台

启动与重启以保存版执行 preflight，复用演出引擎并使用本机音频配置。预检失败保留原运行。刷新只导航 monitor 与已有测试页。底栏控制台在独立窗口显示当前工程的运行日志和编译详情，关闭窗口时保留工作台的编辑状态。展开 monitor 后，显式重启的停止、启动和 ready 周期保持展开，启动占位保留恢复工作台入口。普通关闭、失败或切换工程恢复工作台。[手动测试](./creation-workspace.md#manual-testing-monitor-and-console-156)

创作工作台常驻右侧栏，底部音频区显示运行状态。Internal 工程就绪后，音频区显示主音量前频谱及 DSP 平均、峰值与 Synth 数。展开 monitor 时，频谱居中，读数靠右，作品名和 Git 位置为只读文本。顶栏 monitor 按钮在同一位置切换两个布局，生成 `.pnds` 从工作台的作品菜单打开。[创作 monitor](./creation-workspace.md#creator-monitor-and-performer-surfaces)

### 创作讨论与装机文档问答

讨论默认只读，可读取已保存内容、解释装机文档与逐题确认。未保存草稿通过显式选区附件加入。文档问答仅调用装机文档工具，来源指向真实返回的原语言小节。工作使用当前任务授权，修改 SynthDef 后编译并核验产物。演出占用运行资源时仍做静态诊断，运行验证记录为占用。保存、编译、检查与实际运行分别报告。暂停后可接续原任务，重开工程需显式继续并重新核验授权和输入版本。[创作助手](./creation-assistant.md) · [模型服务](./external-apis.md) · [帮助中心](./help-center.md)

聊天和资料随完整源工程的私有数据携带，物理副本独立保存。恢复历史时只显示已保存内容，中断任务由用户继续。清理或重载前确认，迟到请求不得恢复已清除的内容。[持久化](./data-persistence.md#file-locations)

## 工程选择与历史

启动进入空闲演出视图，恢复上次保存的演出角色。打开文件夹、选择历史条目、导入和打开 `.pnds` 都进入选中与 preflight。工程替换由后续明确的运行操作触发。最近工程与用户文件夹支持排序、移除及拖拽移动。已超限列表完整加载，手动新增遵守每列表 30 个工程的限制，创作新建登记 Home 不受该限制。Utilities 以注册表身份保护成员、别名和顺序。分组切换只改变浏览范围。[角色与侧栏](./performance-participation.md) · [内置工具分发](../zh-CN/reference/pnds-bundle.md)

预检覆盖 manifest、路径与资产、生产依赖、音频通道与 bus、监听端口、模式与 External target、设备能力。迟到结果只在当前请求与配置匹配时可用，选择清除或移除使旧请求失效。[工程预检归属](./state-management.md#project-preflight-ownership) · [manifest](../zh-CN/reference/manifest.md)

## 状态与 Session

Rust session 是 `idle`、`starting`、`ready`、`stopping`、`error` 的真源。选中工程与运行工程分别标记。选卡、导入或浏览分组时，正在运行的 monitor、音量和已应用配置按运行归属显示。

- 运行替换使用两次点击确认。取消、失焦、选择、代次或启动条件变化撤销确认，再次提交时核对目标。命令提交期间防止重复触发。
- 换工程、换音频模式与应用新的 External target 走完整 restart。设备、采样率与 LAN 偏好在下次启动应用。选择及待应用设置在确认期间保留，真实启动或停止按会话结果更新。
- 运行健康告警保留仍可能有声音的演出，当前运行明确失败才清理并进入错误态。入口与 DNS 故障分别报告。[运行期健康](./runtime-health.md)
- 会话恢复接受当前代次的快照。窗口重载或失焦补取时保留比请求更新的实时事件。[状态管理](./state-management.md#session-snapshot-mirrors)

## 网络与 Monitor

LAN 选择用于下次启动，当前页面使用会话实际地址。可用地址变化时重新核对保存选择。monitor 与投影使用受管原生页面，保留同一导航的乐谱实例。尺寸、侧栏和弹层变化只更新布局，显式刷新重建页面。页面焦点或指针在交互区内时，App 的网页快捷键让位，原生菜单按窗口作用域处理。[页面交互](../zh-CN/reference/page-interaction.md) · [原生媒体](./native-project-media.md)

## 跨互联网节点行为

设置保存节点名、hub 地址、遮蔽 token 与 LAN 选择。声明 `telematic` 的工程在节点配置未齐全时显示「设置节点」，仍可关闭当前运行。Room 按工程记忆，默认 1，节点与分组配置在下次启动应用。[环境变量](../zh-CN/reference/runtime-contract.md)

## 可信 HTTPS 准备行为

设置管理域名、端口、证书链和私钥。材料通过校验后原子替换，清除材料保留域名与端口。域名保存后按新值重新校验，失败显示实际状态。设置变化在下次启动应用。[证书材料](./https-material.md)

## 可信 HTTPS 入口行为

工程显式声明需要可信 HTTPS 时按能力、开关与材料决定启动入口。未适配且启用开关时要求确认使用 HTTP。确认取消保留现有运行。已适配工程在所需材料无效或监听失败时明确报错。工程 ready 与入口 ready 分别显示。[HTTPS 网关](./https-gateway.md) · [浏览器参与协议](../zh-CN/reference/browser-participation.md)

入口运行中故障保留本地音频与服务，HTTPS 地址保留用于诊断。操作者重启演出恢复入口。停止、替换和失败清理释放旧入口，迟到探测不能修改新演出。

## 演出 DNS 行为

设置注册或注销系统守护进程，显示真实监听与映射状态。映射随实际 HTTPS 演出建立、验证和撤销。映射失败独立反馈。普通 DNS 转发随守护进程运行。[DNS 服务](./dns-service.md)

## 音频 Host 行为

- 显示 manifest 允许的模式。仅 Internal 启动本机音频引擎。设备能力按有效采样率枚举，通道不足时显示损失并允许选择。[运行契约](../zh-CN/reference/runtime-contract.md)
- Internal 每次启动重新解析设备并向 scsynth 传入显式设备名。已选设备不可用时提示并使用系统默认，解析后再消失按启动失败处理。scsynth 启动时的信号死亡最多透明重试三次，耗尽或其他失败进入错误态。
- 静音保存会话内恢复音量。滑杆调到零视为静音，调高解除。⌘M 与静音按钮共用动作和禁用条件。仅 ready Internal 单／双声道允许调节，初始增益 80%，多声道按运行契约固定增益。[静音快捷键](./keyboard-shortcuts.md#mute-shortcut-v122-issue-30-feedback)

## Window 与全屏

Pond、Sand、Stage 使用原 AppKit 按钮组并保留原父视图和 target/action。Brutal 窗口化保留直角、borderless 与标准按钮工厂 overlay，绿色按钮通过 Tao 的全屏准备和恢复。全屏使用系统标题栏按钮。主题、全屏和布局变更沿用同一 NSWindow、App webview 和已加载乐谱。窗口持久化排除 `VISIBLE` 和 `DECORATIONS`。

主窗口隐藏创建，应用主题后揭示。偏好读取失败仍显示，Rust 有超时兜底。主窗口原生关闭事件淡出隐藏并保留演出，Dock 重开淡入。动画打断时恢复一致的透明度。

池主演出已就绪时，主窗口第一次 ⌘W 在左下角显示「再次按下关闭工程」。再次按 ⌘W 或点击亮起的按钮关闭当前运行工程。Esc、点击按钮外、窗口失焦、选卡变化或运行代次变化取消确认。若已选中另一张卡，确认关闭后保留该卡。会话正在启动时，⌘W 使用「停止会话？」确认停止并隐藏窗口。⌘Q 先处理未保存草稿、聊天和交接，再清理并退出。

池客保有演出页面时，主窗口第一次 ⌘W 在左下角显示「再次按下退出演出」。再次按 ⌘W 或点击亮起的按钮退出当前演出，主窗口继续显示。Esc、点击按钮外、窗口失焦、当前演出或所选池主变化取消确认。长按 ⌘W 只算一次。

帮助和投影按焦点分发 ⌘W，关闭各自窗口。帮助窗口支持双语语料、实时搜索和失败重试。[帮助中心](./help-center.md#窗口与导航)

## 投影窗口

底栏打开投影单实例。投影已打开且会话 ready 时，同一按钮切换开演与撤回。窗口位置和全屏不随工程切换重建。投影在 App 当前显示器打开，关闭后下次打开重新选位。开演状态属于 Rust 会话，换工程重置，关窗重开沿用当前状态。

| 会话状态                | 开演及地址         | 内容     |
| ----------------------- | ------------------ | -------- |
| starting 或 ready       | 未开演，或地址缺失 | 工程简介 |
| ready                   | 已开演且地址有效   | monitor  |
| idle、stopping 或 error | 任意               | 待机     |

投影 monitor 导航携带 `surface=venue`。主题、语言和显式刷新沿用主窗口契约，页面就绪后揭示。快照恢复失败也揭示待机。投影使用自己的缩放偏好，作用域随焦点。当前 monitor 页面声明自管缩放后，App 在该导航使用 100% 且暂停其缩放动作，下一导航重新判定。[投影协议](../zh-CN/reference/runtime-contract.md) · [快捷键](./keyboard-shortcuts.md)

### 封面页

主窗口 README、创作预览与投影简介共用封面。固定 1200 × 800 构图等比缩放，编辑元数据与首节简介沿用文件草稿。内置工具按注册表渲染共享工具信息页，README 缺失时显示工程名。[封面布局](./ui-patterns.md#readme-cover-composition) · [README 指南](../zh-CN/readme-guide.md)

## Sidebar

空闲或错误时显示侧栏，运行时侧栏覆盖 monitor。边缘悬停、按住 Cmd、选择其他工程、打开 App 弹层或提交运行操作时保持显示。只有回到运行卡且保留条件均结束时才自动收起。隐藏侧栏退出键盘遍历。右键「打开工程」沿用 Load 和替换门控，「开始创作」固定该卡为目标并在必要时确认停止另一工程。[侧栏布局](./ui-patterns.md#performance-overlay-sidebar) · [原生选卡](./keyboard-shortcuts.md#native-performance-selection-202)

## Loading、Error 与 Retry

Loading 等待真实 session ready 和当前页面导航就绪。页面等待 10 秒后允许揭示并记录超时。恢复被挂起的窗口时跳过过期动画，仍等待当前会话和导航。停止覆盖旧页面，切换工程直接接入下一次 loading。刷新使用新导航 nonce 冷加载，保留运行进程。[页面运行契约](../zh-CN/reference/runtime-contract.md)

错误页显示摘要、Retry、返回或关闭，以及可展开和复制的工程、配置、阶段、输出与 health 详情。Retry 通过新 generation 重新启动并防止重复提交。返回 Welcome 等待用户选择。低于 Safari 16.4 的已识别版本显示 WebKit 更新说明。

## 更新检查

启动检查静默报告可用新版，失败不弹窗。手动检查报告已最新、新版或失败。下载入口打开 Releases，安装由操作者完成。[发行](./releases.md)

## 日志与清理

每个会话记录配置、阶段、子进程输出、健康变化和清理结果，保留最近 20 份。关停期间输出仍按 generation 记录。先释放工程服务，再释放音频引擎。实际退出和下次启动清理按进程所有权执行。[日志](./logging.md) · [受管进程](./rust-architecture.md#supervised-child-processes-childrenrs)

## 演奏端二维码

共用底栏网络面板在演出显示稳定公开入口，空闲时可扫码等待。创作仅在当前工作区拥有 ready 测试时显示实际测试地址。二维码与复制使用相同 URL，创作测试不发布公开演出。弹层关闭、运行代次或 URL 变化使旧结果失效。[网络邀请](./network-invitations.md)

## Creation performer test windows

各测试窗口拥有独立页面和设备布局。改变尺寸保留页面，刷新重新导航，重启测试保留窗口和浏览器身份。连接状态由工程名册提供，与页面加载分别显示。窗口支持原生 JavaScript 弹窗和鼠标单点触摸模拟。关闭窗口隐藏页面，从列表删除才释放该客户端。离开工作区或切换工程时释放其测试窗口。[测试窗口](./creation-workspace.md#independent-performer-windows-157) · [页面交互](../zh-CN/reference/page-interaction.md)

## Offline module addition

可编辑工作台从内嵌资源添加源码和采用记录。文件加入后仍需接线与检查。已有作者源码保留，失败重试复用已确认的采用事实。[标准模块](./standard-modules.md)

## 确认交接与返回比较

确认交接后写入正式任务并记录保存版基线。有草稿时明确选择先保存或仅使用保存版。基线失败可重试，起点沿用原确认。返回比较只读展示当前保存版的实际变化，草稿另列。[交接基线](./handoff-baselines.md)

## 演出记录与录制轮次

录制、回放和轮次管理共用底栏入口，采用已确认的 A 紧凑弹窗。列表页最大高 420px，固定头部与工具栏，记录列表内部滚动；每条只显示时间，整行共用打开与悬停区域，右侧 × 仅悬停或行内聚焦时显示。文件夹与导入图标靠右，导入位于最右；原生文件选择和拖入均逐个调用既有 Rust 校验，并绑定发起时的工程路径与创作身份，切换工程后的晚结果不会进入新工程。详情显示返回、时长、上箭头导出与默认折叠的轮次管理，不再显示记录信息区。

记录和轮次均在原行首击准备删除，以 180ms 从左到右显现红底，第二次点击该行才删除；Esc、外部按下、窗口失焦、收起、工程所有者变化或进入活动／忙碌状态取消准备，不新增下方确认块。收起、返回列表或隐藏窗口保留当前操作。所有开始操作直接使用当前运行工程，并预授权内容变化，不显示工程兼容性、版本变化或播放效果提示；真实存储、文件损坏与运行失败仍按事实反馈。录制与重录成功后发布记录，放弃或失败保留原完成版。源工程的私有记录随完整目录携带，副本独立。详情可删任意非活动轮次并保留公共乐谱与时长。HTML 仅用于设计核对，不能代替真实声音与原生设备验收。[演出记录](./performance-recording.md)
