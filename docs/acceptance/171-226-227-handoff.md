## Native regression matrix

The observations above cover specific paths through this matrix, not every
combination of theme, keyboard input, project and runtime.

Use disposable writable source projects, one without Git and one existing Git
repository. The user starts the App/dev server. Test all four themes, keyboard
focus/Enter/Space/Escape, long filenames and a narrow window.

1. Ask the assistant for new/cross-file module wiring or a complex preview
   adapter. Inspect the reason, files, known problems and acceptance; decline,
   cancel the prepared dialog, then review and confirm. Confirm one stable task
   ID/revision, preserved existing agent status and copyable instructions.
2. Repeat with ordinary file drafts and a draft of `docs/creator-handoff.md`.
   Exercise both draft choices. Cause an external save conflict during save-first
   and cancel. Saved-only must keep the handoff draft and show its conflict with

   active. Neither enters the baseline or is implicitly applied by save-first.
   If wanted, explicitly apply in its original card and review a new handoff;
   otherwise describe the unimplemented plan as a task requirement. The scoped
   #208/#231/G5 **None** integration was exercised above; broader real-work and
   physical audio acceptance belongs in #172.
4. Use an external editor to change/add/delete text and replace an audio/image
   resource. Commit externally in the Git copy until its working tree is clean.
   Reopen the App, select the original baseline and inspect actual text and
   resource summaries. The App's own original handoff append must not appear as
   a later external change. A subsequent manual edit must appear too.
