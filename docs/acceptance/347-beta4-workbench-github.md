# Beta 4 创作工作台和 GitHub 联合实机验收（#347）

对应 [#347](https://github.com/xO-xN/PNDS-App/issues/347) 与[父规格的 16 个场景](../plans/v1.7.0-beta.4-creator-project-versions-spec.md#场景验收)。交互以[确认过的 HTML 原型](../prototypes/creation-project-versions.html)为准。此表是实测步骤和记录模板。GitHub 与 macOS 实测尚未录入。

## 准备

在本次集成候选的同一检出运行 `npm run tauri:dev`。记录候选提交（`git rev-parse --short HEAD`）、macOS 版本与机型。使用空白测试工程、专用公开和私有测试仓；准备仅选定仓库的 GitHub App 安装及一个限制创建公开仓库的组织。按[注册说明](../developer/github-sync.md#github-app-registration)配置客户端 ID、App slug 和权限；如有旧安装，先保留未批准新增权限的状态供场景 03 检查。只记录账号标识和测试仓名称，凭据及设备授权码留在本机。若没有组织或旧版安装，记为待测。

GitHub 端记录仓库 ID、可见性、模板来源、默认分支和 HEAD。用独立克隆检查 `git show -s --format=fuller HEAD`、`git log --graph --all --oneline`、`git ls-tree -r --name-only HEAD`。比较发布合并提交和确认的本地提交的树 ID（`git rev-parse <提交>^{tree}`）；两段历史均应可达。每次中断先记录实际远端状态；精确注入响应丢失和本地记账失败的证据与人工断网分别登记。
