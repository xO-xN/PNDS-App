- 原始历史来源数组和版本／范围不迁移。来源链接打开当前装机文档，范围详情明确属于记录时版本；不把旧 offset 解释成当前原文坐标。

## 检索与读取

`help-retrieval-cases.json` 定义 24 个概念／任务意图，每个有中英文及关键词／问句，共 96 个输入。每题指定权威文档和可接受小节。关键问题涵盖音频、OSC、页面角色、SynthDef、字段、资料、上下文、任务接续、版本、交接、检查和迁移；未知概念另测无证据返回。

保留词法搜索，加入有限问句归一、中文多字词及只含目标的概念路由。空标题不占位；完全相同的 Markdown 正文折叠，不合并否定、数字或版本操作符不同的规则。相近内容不作语义去重。

搜索返回短 Markdown 范围和可直接传给原阅读工具的 readTarget，按命中段落给出该小节的 UTF-16 坐标。搜索／阅读共享版本和范围复用，旧阅读调用语义不变。默认／最大页长及既有预算、取消和作用域保护继续有效。现有 H2 已可覆盖本轮任务，未增加第二份正文或更深标题解析器。

来源按文档版本、小节分组，同节分页只显示一个链接，范围可展开。项目／资料原有快照和导航独立保留。分组改善显示，不计作模型 token 节省。

## 确定性证据

数据见 [回放记录](./evidence/documentation-retrieval.json)。before 来自本轮开始时的实际工作区文件快照，并使用当时检索与工具代码；after 使用整理后的语料和实现。

| 指标                                             | 中文 before → after | 英文 before → after |
| ------------------------------------------------ | ------------------- | ------------------- |
| 固定问题权威文档进入前三项                       | 27/48 → 48/48       | 27/48 → 48/48       |
| 完全相同段落组（空白归一、至少 60 字符、跨文件） | 12 → 0              | 12 → 0              |
| 默认“模型服务”搜索后一次读取的新正文字符         | 1200 → 81           | 1200 → 254          |
| 同次读取复用搜索范围字符                         | 0 → 53              | 0 → 64              |
| 该搜索＋读取的工具结果 UTF-8 字节                | 5072 → 2255         | 2782 → 2166         |

96 个输入验证具体检索结果，不代表所有自然问句都能命中。旧语料没有部分新增小节，所以新小节命中率仅用于 after 断言，不与 before 直接作质量百分比比较。“模型服务”是相同查询的一次固定工具回放，不是完整答案质量或累计 token 的比较；这些字节和字符不称为 token，也不代表真实模型耗时。
