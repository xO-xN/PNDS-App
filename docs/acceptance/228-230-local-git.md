# #228–#230：本地 Git 与历史草稿验收记录

本轮实现基于 `1a33652340d1eae3981606ff03c6bce166a72834`，按 #228 → #229 → #230
接入 G7。本文区分自动化契约证据与用户启动真实 App 的验收，不以测试替代原生页面或声音。

## 已实现的公开工作流

- #228：Blank／Classic 发布前建立独立仓库及初始版本；独立可修改署名和本机邮箱占位；
  已有工程预览后主动启用；初始记录失败保留仓库、重新预览后补齐。
- #229：保存版完整文件选择、差异与说明预览、最终确认；提交树只含所选文件，外部
  index 隔离；文件／HEAD／index／配置变化、锁、冲突、filter／签名等明确拒绝。
- #230：真实提交身份／时间／署名／说明／文件清单，最多 30 条相关记录／扫描 300 条；
  历史、当前保存版与草稿分别核对；已有草稿保留／取消／明确替换，仅载入现存文本草稿。
  保存继续验证当前磁盘版本及内容规则，不重建删除文件，不回退 Git，不改变运行。

生产引擎为静态链接 `git2 0.21.0`／`libgit2 1.9.7`，关闭 SSH／HTTPS feature，
无系统 Git 进程。固定许可与来源文本进入 `licenses/LOCAL-GIT.txt`。范围及资源上限见
[开发规则](../developer/local-git.md)。

## 自动化证据

Rust 公开 `CreationAccess` 工作流在真实临时目录／标准 Git 仓库验证创建、主动启用、
署名和邮箱、首条失败重试、特殊文件名的新增／修改／删除、未选外部暂存条目及最终树、
大资源默认规则、外部磁盘／HEAD／index 竞态、签名／filter／锁／冲突拒绝、历史读取与
磁盘版本核对、删除／二进制／目录／缺失／越界／不可达历史。#201 原有只读测试继续覆盖
父仓库、linked worktree、分层差异、外部程序标记及缺对象 partial clone 的完整前后盘点；
该 fixture 同时拒绝新增历史与写入预览，未调用 transport helper。

清空环境变量并将 PATH 指向不存在目录的子进程，执行两种模板、后续完整文件记录与
历史读取。arm64 已通过；Intel 目标已成功交叉编译；当前宿主无 Intel／Rosetta 执行环境（os error 86），
该架构测试程序未执行。发行安装环境与声音仍待用户原生验收。

React 公开用户工作流验证新建署名独立、启用前预览／最终确认、外部暂存禁选、保存版
差异、失败保留说明并重新预览、保留已有草稿后明确替换、加载后显式保存冲突，以及
编辑／工程切换后的迟到结果拒绝。类型安全命令绑定与中英文文案同步。

`npm run check:all` 已全部通过：typecheck、ESLint、ast-grep、Prettier、rustfmt、
Clippy、前端 169 个文件／1,913 项测试，以及 Rust workspace 610 项测试（5 项 ignored）。
完整检查在允许本机回环端口的环境运行；受限沙箱会阻止原有 HTTP 集成测试监听
`127.0.0.1`，产生 EPERM，解除该限制后这些测试全部通过。

## Standards

相对上述基准独立审查。两项发现均已修复并复核：记录确认期间阻止关闭与刷新，保留
真实提交回执；记录状态、排除原因与历史限制原因使用有限枚举及生成的 TypeScript 联合。
无剩余可操作问题。

## Spec

相对 #228／#229／#230 独立审查。三项发现均已修复并复核：拒绝 EOL／属性转换，
避免保存版差异与提交原始字节不一致；初始化后任一步失败均说明已有仓库及补齐路径；
在首次解析前限制 index，按每次树引用累计路径／深度，限制重复子树和深历史。
公开工作流回归测试覆盖这些边界。无剩余需修改问题。

审查结果：Standards 原有 2 项、剩余 0 项；Spec 原有 3 项、剩余 0 项，两轴均无剩余最严重问题。

## 用户启动 App 后验证

使用本轮构建，在 arm64 和 Intel 发行安装环境断网并移除系统 Git／CLT／Xcode 可用性，
新建 Blank 与 Classic，查看初始提交树和署名；已有无 Git 工程先取消再主动启用，
制造首条失败后重试；父仓库、worktree、嵌套仓库均不执行不支持的写入。

编辑并保存多个文件，另留草稿、待应用建议和临时预演。手动记录部分文件，核对真实
提交 ID、树和未选 index；制造预览后的文件／HEAD／index 变化，确认停止旧确认并保留
用户说明。记录成功后的刷新失败仍应显示真实提交 ID，不能据此重复提交。

选择历史现存文本，先保留已有草稿，再明确替换、核对、保存并手动测试；加载时磁盘、
index、HEAD、monitor 与声音不变。加载后外部修改再保存，确认保留双方工作并拒绝旧版
覆盖。验证删除、二进制、越界链接和不可达历史无恢复副作用。

四主题、中英文、Tab／Enter／Space／Esc、焦点返回、长路径／长说明、进度与失败反馈，
以及真实设备／monitor／声音均待用户原生验收。这里只记录契约已验证，不据此关闭 G8
或宣称最终双架构发行与完整创作艺术效果已通过。
