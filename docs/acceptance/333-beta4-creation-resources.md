# Beta 4 创作资源联合验收（#333）

本记录区分受控检查和实际音画。保存一份专用测试工程，并用本次集成候选启动 `npm run tauri:dev`。记录提交、macOS 版本、显示设备、系统默认输出、PNDS 底栏所选设备，以及 WAV、MP3 和图片的格式、大小、采样率或尺寸。

| 路径              | 操作与应记录的实际结果                                                                                                                                                                                                                  | 实机                   |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| 创作资源与拖放    | Finder 一次导入文本、图片、WAV、MP3。核对导入只列入收件箱、图片缩放和平移、引用标签显示在输入框上方、误拖到其他区不弹系统错误。工程文件拖入助手和 Finder、待用文本拖入助手已获此前用户确认，见 [#335](./335-beta4-file-references.md)。 | 新版布局与媒体拖入待测 |
| 本机试听          | 按[试听实测步骤](../developer/pending-documents.md#macos-acceptance)，用与系统默认不同的实体输出验证实际出声路径、长录音定位、Internal 生效设备、External／None／静音和拔掉设备后的停止。                                               | 待测                   |
| Performer 背景    | 在 Blank 的「工作」任务仅选一张待用图，要求作为背景。记录接入路径、具体保存的代码、静态及受控结果；启动工程，看真实页面的背景和构图。                                                                                                   | 待测                   |
| Performer 播放    | 用真实「工作」任务把 WAV／MP3 接到页面播放控件，记录实际资源 URL 与代码，观察控制台及受控结果，按控件听到指定音频并记录开始、暂停和定位。                                                                                               | 待测                   |
| SuperCollider WAV | 用真实「工作」任务接一个 WAV 采样，记保存的工程路径、加载代码、静态及受控结果。启动工程所需音频模式，触发约定事件并记录实际听到的采样及输出。受控载入缓冲并不等同实际演奏出声。                                                         | 待测                   |
| 一次接入和恢复    | 同一次任务选待用文档、图片、音频，另留一个仅查看的候选。确认完成后采用项一起消失，候选仍在。关闭重开后分别试整次撤回与仅恢复原件；记录同名、较新修改、失败、取消和过期时的结果。核对实际已接入文件能进入普通工程版本和演出包。          | 待测                   |

回复可按表的行名说明通过、失败或没测，并带一项实际观察。控制台或受控检查报告可作为技术证据，真实听到和看到的结果另记。
