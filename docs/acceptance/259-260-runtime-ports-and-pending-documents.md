## 实施与自动化证据

工程显式声明 `scoreServer.runtimePorts: 1` 后，由 App 真实绑定 performer／monitor
监听器并交给 Node 继承。启动结果先核验本次运行、角色、实际端口及持有者，再请求
health；预检空闲不作为端口保留证明。没有该声明的工程保持固定端口，不修改 manifest。
health、monitor、普通浏览器入口、转发与诊断消费当次实际分配。池客入口状态与本机
演出状态分别记录，入口故障不能把健康的本机演出误报为已经停止。

真实受管启动测试覆盖两项首选端口均被占用、非法绑定结果、错误 health、取消、
停止与重试、旧工程兼容，以及入口的资源、查询参数、polling 和 WebSocket 往返。
测试只拥有自己的进程与端口，验证原占用者继续存活、所属监听器与连接确实释放。

清理记录不可读、损坏、无法持久化或仍有未确认进程时，公开启动在任何新端口分配前
失败并保留归属。替换演出仍保留旧进程句柄并确认回收，不能依靠损坏的磁盘记录
释放已知进程，也不能由已知句柄清理成功抹掉未知记录的失败状态。真实公开流程
覆盖演出 A 就绪、记录损坏、B 被拒绝、A 回收、修复记录后显式重试。

待处理文档通过原生命令在真实临时工程上验证独立文件、旧资料迁移、原始 UTF-8／
CRLF 字节、容量限制、外部修改与重命名、版本冲突及中断恢复。保存版为不透明修订，
正文有独立指纹；同正文重命名也会使旧写入许可失效。主编辑器测试覆盖首次保存、
切换保留、保存／放弃／取消、Finder 与删除入口、外部冲突、快捷键及工程版本保存。

助手请求携带保存版清单，按需读取正文；整批接入在完整来源、全部目标、引用与真实
检查事实核验后，先持久化整任务恢复记录，再统一移出原文。测试覆盖失败保留、实际
Node 入口接线、任务日志退休后的跨重启撤回、较新修改保护及仅恢复原文。
接入完成后本任务的写权限终止，不恢复历史授权。

## 池客来源验证

原生机制验证发现：`tauri://` 父页面的第三方 iframe 不能作为持久恢复已经成立的
证据。因此正式接入采用同一窗口内的第一方原生谱面子视图，使用稳定 `.localhost`
来源和创建时代理配置，将浏览器来源与实际回环传输端口分开。

`scripts/verify-native-client-view.mjs` 使用临时目录、自有监听器及两个独立原生进程。
稳定网址的端口被自有占用者持有时，更换实际代理端口后仍验证 localStorage、
IndexedDB、持久 cookie、真实 Worker、polling 和 WebSocket。占用者继续监听且没有
收到谱面请求；不同来源的存储隔离单独核对。夹具还持续写入 localStorage，
关闭原生文档后同步，分别在同进程重建与独立进程重启后恢复最后一笔已确认写入，
并确认旧定时器不再写入。125% 窗口缩放下，560 AppKit point 的谱面视图提供
448 CSS px 视口，重启和同进程重建均核对。这个机制夹具不等于完整签名 App 验收。
2026-11-04 的最终 `npm run native:client:verify` 在 macOS 27.2 arm64 通过，
证据文件为本机临时目录 `pnds-native-client-view-dgEvNg/evidence.json`，
`passed: true`、`foreignHits: 0`；夹具源码 SHA-256 为
`b7346d44fd713aa8a173b79e51d9463509458ddc9db45c7ff90b0ba9c373f0e4`。
实现不提高 macOS 13.5 最低版本；当前机器的原生结果不能替代 13.5／Intel 验收。
原生视图不注册为第二个 Tauri webview，保留现有主窗口命令的归属；退出先关闭
文档，再同步存储。同步失败保留待重试的存储归属，仍关闭所属 HTTP／WS 转发；
只有存储和连接均确认收尾后才报告离开完成。
