## 实施边界

聊天继续复用资源发现、组合确认和同任务继续。native 规则把 hub 请求扩展为确切的 Node `socket.io-client` 依赖；确认后采用共享引用、根生产声明及模块，全部进入原任务恢复与撤回。相同确切资源不重复采用，不同版本明确失败。已加入或作者定制的 hub 保留源码，后续接线读取真实保存版。

当前 hub 模块通过 Host 已校验的绝对共享入口加载客户端；有注入映射时不能靠裸导入、本地安装或运行时网络回退掩盖缺失资源。普通新增资源及助手独立推荐隐藏未采用的 `socket.io-client` 与 `qrcode`；已采用事实、底层精确引用解析、既有自定义工程及 App 二维码编码器继续保留。

hub 保持按需连接既有中继，不默认加入 Blank、不创建中央 hub。Host 配置归属、本地演奏自治、主题与语言的按需接线保持原契约。资源采用成功之后，助手仍需完成当前工程的 `telematic` 声明、配置使用、事件校验与应用、状态观察和关停接线，再核对实际运行；复制文件或共享引用不是完成证据。
