## 关闭依据与本轮复验

- #196／#211：采用时原子更新确切引用与工程版本，沿用身份、来源、路径、草稿与磁盘冲突保护。有限共享目录、生产锁树和实际浏览器／Node 接线均已实现。七项库资源的完整性、损坏与错版失败、旧自包含兼容由公开工作流回归覆盖。
- #197：App 实际 `pack → install` 的 p5／qrcode 工程在两个同源 HTTP 入口冷打开与刷新均绘制 64×64 canvas，像素 `[20,40,60,255]`。外网阻断探针实际失败；关闭进程后端口重新绑定。既有候选包往返核对所有工程文件与模型哈希，共享资源不物化入包，失败安装保留旧安装。
- #211：真实 CJS／ESM、Express HTTP、QR 目标、Socket.IO 双向事件、断线重连和有界关停通过；生产资源不依赖维护者 `node_modules`，运行时不安装依赖。
- #212：本轮 Mobile Sensor Meter 0.4.1 从工程加载 detector／landmark 两份 JSON 和两份权重分片，均为 HTTP 200；实际 ml5 1.4.0 WebGL 推理得到零手，约 311 ms。使用灰色 canvas，无设备输入，外网请求被阻断，工程无本地 `node_modules`。这项自动化不代表摄像头、麦克风或运动权限验收。
- #196／#212 可信 HTTPS 人工证据：用户在明确询问「App 1.6.2 的可信 HTTPS 入口下，p5 页面绘制与 Mobile Sensor Meter 模型推理」后回复「已经在最近那次功能调整时重做过」。据此确认这两项通过，不扩展为其它工具／音频模式／完整手机传感器流程已验收。
- #213：osc-min 2.1.2 的 ESM 入口及 DataView 视图字节转换已适配；独立 UDP wire golden 核对真实地址和载荷，未向无关外部声音目标发包。
