# 可信 HTTPS 入口准备

为需要浏览器安全上下文的演出配置可信 HTTPS。

## 为什么需要它

手机扫码和普通触摸使用 HTTP。作品需要浏览器传感器、摄像头或麦克风等安全上下文能力时，按 [manifest 声明](./manifest.md)启用 HTTPS。

## 准备清单

准备可控制解析的 DNS 域名、公有 CA 签发的完整证书链及匹配私钥，以及能配置本地 DNS 的演出网络。

## 第一步：域名

在**设置 → 可信 HTTPS**填入具体域名，例如 `show.example.org`。域名不带协议、端口、通配符或 `.local`。

## 第二步：取得公有证书

取得有效的 PEM 证书链（leaf 与中间证书）和匹配私钥。证书 SAN 须覆盖配置域名。

## 第三步：在 App 中导入

在**设置 → 可信 HTTPS**导入材料并启用。App 校验格式、有效期、私钥、信任链和域名覆盖。导入失败保留现有材料。私钥存于本机受保护目录。

## 第四步：路由器本地 DNS

用路由器本地 DNS 或 [演出 DNS](./dns.md)把域名解析到所选 Mac 的 LAN 地址。手机连演出 Wi-Fi，扫码确认页面和所需权限可用。

## 到期与更换

App 显示到期时间，提前 30 天提示。续期后重新导入。证书、域名、端口和开关改动在下次启动工程时生效。

## 常见错误

| 问题               | 处理                           |
| ------------------ | ------------------------------ |
| 证书过期或尚未生效 | 检查系统时间，必要时续期并导入 |
| 域名不匹配         | 使用证书覆盖的域名或换证书     |
| 链不完整或不受信任 | 导入公有 CA 完整证书链         |
| 私钥不匹配         | 导入对应的私钥                 |

## 入口生命周期（#140 起）

启动适配的工程后，入口状态显示准备中、就绪或故障。就绪表示本机入口探测通过，手机连接仍由实际扫码确认。

## 故障恢复与切换隔离（#141 起）

启动失败时按提示修复端口或证书配置再试。运行中入口故障时，本地服务与音频继续运行。修复后停止并重新启动工程。

## 与工程的关系

完整 performer URL、入口选择与浏览器 origin 规则见[浏览器演奏接入](./browser-participation.md#完整-performer-url-与可信-https)。
