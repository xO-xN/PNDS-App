# 演出 DNS：手机零配置入网

演出 DNS 为[可信 HTTPS](./https.md)入口提供场地内解析。

## 为什么需要它

后台服务将当前演出的 HTTPS 域名映射到池主 Mac，并转发其他域名。

## 启用前检查

使用 macOS 13.5 或更新版本，为 Mac 保留 LAN 地址，在 App 选定该地址并配置可信 HTTPS。

## 第一步：在 App 里启用

在**设置 → 演出 DNS**启用后台服务。按系统提示授权。

## 第二步：路由器把 DNS 指到这台 Mac

在路由器 DHCP 中将 DNS 设为池主 Mac 的 LAN 地址。设备重新连接 Wi-Fi 后取得设置。使用期间保持 Mac 在线。

## 第三步：开始演出

启动可信 HTTPS 入口后，App 安装并验证当场的域名映射。手机连演出 Wi-Fi 后扫码。

## 停止与清理

停止或切换演出会撤销映射，普通域名继续转发。App 意外退出时映射随租约到期撤销。关闭 DNS 服务或移走 Mac 前先恢复路由器 DNS。

## 排错

| 症状           | 处理                        |
| -------------- | --------------------------- |
| 演出地址打不开 | 检查 HTTPS 入口和演出映射   |
| 普通网页打不开 | 检查 Mac 在线状态及上游连接 |
| 等待系统授权   | 在系统设置批准 PNDS 服务    |
| 53 端口占用    | 释放端口后重新启用          |
