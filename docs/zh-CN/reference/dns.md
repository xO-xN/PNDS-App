# 演出 DNS：手机零配置入网

面向演出 Host 操作者：用 PNDS 的后台 DNS 服务，让乐手**只连 Wi-Fi、扫码即可加入**，同时**不影响场地里其他人的日常上网**。与运行时契约的对应关系见 [runtime-contract.md](runtime-contract.md) §16。

## 为什么需要它

没有它时，手机访问演出域名要靠三选一：手动改手机 DNS（每次演出都要教乐手）、路由器逐条写 DNS 记录（多数现场路由器做不到）、或者放弃域名直接用 IP（HTTPS 证书校验会失败）。演出 DNS 把这三件事都消掉：路由器只需**一次**把 DNS 指向这台 Mac，之后演出域名的解析跟随 App 的演出生命周期自动安装、自动撤销。

## 启用前检查

| 检查项                  | 说明                                                            |
| ----------------------- | --------------------------------------------------------------- |
| macOS 13.5+             | SMAppService 是系统要求                                         |
| 固定局域网地址          | 本机 LAN IP 若经常变动，去路由器管理页把它设为静态（DHCP 保留） |
| 「节点」区已选 LAN 地址 | DNS 映射使用与 HTTPS 入口相同的所选地址                         |
| 证书已导入              | 映射的域名就是「可信 HTTPS」区配置的域名                        |

## 第一步：在 App 里启用

设置 → 「演出 DNS」→ 打开「启用后台 DNS 服务」。首次启用时 macOS 弹出一次性授权（LaunchDaemon 登记），批准后服务立即开始运行，并随登录与重启自动恢复。授权被拒绝或关闭时，状态行会显示「等待系统授权」，提供打开系统设置的直达按钮。

启用期间普通域名转发到 App 内置的默认上游（公共 DNS，双上游自动故障切换），无需配置；状态块会显示守护进程当前实际使用的上游。

## 第二步：路由器把 DNS 指到这台 Mac

在演出路由器的管理页（以 TP-Link TL-WR800N 这类只支持 DHCP 下发 DNS 的小路由器为例）：

1. 进入「DHCP 服务器 → DHCP 设置」；
2. 把「首选 DNS 服务器」改成本机 LAN IP（例如 `192.168.11.31`），备用 DNS 留空或填本机地址；
3. 保存并让路由器重新下发（手机重连 Wi-Fi 即生效）。

⚠️ Mac 关机、休眠或离网后，全场的 DNS 都会失效——这是「用本机当 DNS」的物理边界。演出散场后若场地需要继续上网，把路由器 DNS 改回原值（通常是上级运营商/网关地址），或改用一台持续在线的专用 DNS 设备。

## 第三步：开始演出

启动声明了 `supportsPerformerUrl` 且 HTTPS 开关已开的工程时，App 自动把 HTTPS 域名映射到所选 LAN 地址，先在守护进程内部验证解析结果，再发布入口。乐手侧：

1. 连接演出 Wi-Fi；
2. 扫码（或输入演出地址）；
3. 打开页面、参与实时控制。

乐手的手机上**不需要**安装证书、VPN，也不需要改任何 DNS 设置。

## 停止与清理

- **停止工程 / 切换工程 / 退出 App**：演出映射随会话撤销，域名立即停止解析（不再指向旧地址，也不转发公网）；普通域名转发继续，场地日常上网不受影响。
- **App 意外退出**：映射带租约（60 秒），超时后守护进程自动撤销，不会残留。
- **停用服务**：设置里关掉开关——守护进程注销并停止，端口释放；此时路由器 DNS 还指向这台 Mac，但没人应答，**务必按第一步反向操作恢复路由器 DNS**。
- **卸载 App**：删除 App 即卸载守护进程；同样先恢复路由器 DNS。

## 排错

| 症状                         | 处理                                                                                                 |
| ---------------------------- | ---------------------------------------------------------------------------------------------------- |
| 手机扫不开页面，日常网页正常 | 设置 → 演出 DNS，看「演出映射」行是否存在；不存在则确认工程声明了适配且 HTTPS 开关已开、入口为 ready |
| 日常网页打不开               | 上游不通：检查 Mac 自身联网（默认上游为公共 DNS，需能出公网）                                        |
| 状态显示「等待系统授权」     | 点「打开系统设置」，在登录项与扩展里批准 PNDS                                                        |
| 53 端口被占用                | 另一个 DNS 服务在跑（如其他工具装的 dnsmasq）；先停用它再启用本服务——PNDS 不会抢占或杀掉已有服务     |
| 部分网页间歇性失败           | 一般是网络本身抖动；转发带双上游超时切换，长期失败再查上游                                           |
