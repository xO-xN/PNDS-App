# 页面交互：键盘、指针与触摸

monitor 与 performer 页面接收标准 Web 输入事件。

## 总则：嵌入模型与键位两层

macOS App 以[原生页面](./native-media.md)承载 monitor 和测试 performer。macOS 菜单加速器按窗口范围生效，主窗口的 Web 快捷键在页面交互期间让位。

## monitor 页键盘

### 表 A：原生层在启用的窗口范围内保留

| 键位              | App 行为                                                               |
| ----------------- | ---------------------------------------------------------------------- |
| `⌘ W`             | 关闭窗口或确认停止当前工程                                             |
| `⌘ Q`             | 退出 App（运行中有确认流）                                             |
| `⌘ M`             | 主输出静音 / 恢复                                                      |
| `⌘ O`             | 导入工程                                                               |
| `⌘ R`             | 重命名选中的工程 / 文件夹                                              |
| `⌘ ,`             | 打开 / 关闭设置面板                                                    |
| `⌘ ?`（⇧⌘/）      | 打开帮助中心                                                           |
| `⌘ 0`             | monitor 缩放：实际大小（按聚焦窗口）                                   |
| `⌘ =` / `⌘ -`     | monitor 放大 / 缩小（按聚焦窗口）                                      |
| `⌘ ⇧ R`           | 重载两个窗口的 monitor 页                                              |
| `⌘ ⌥ ↑` / `⌘ ⌥ ↓` | 上下选卡；仅演出主窗口                                                 |
| `⌘ ⌥ Enter`       | 加载准备好的选中工程；运行中替换先确认；运行卡变更则重启，未变更不操作 |
| `⌃ ⌘ F`           | 聚焦窗口进入 / 退出全屏                                                |

缩放和全屏作用于聚焦窗口，刷新同时重载主 monitor 与投影。投影可按[运行契约](./runtime-contract.md)声明页面缩放。

### 表 B：条件可用——页面交互期间属于页面

| 键位        | 平时（页面未交互）的 App 行为 |
| ----------- | ----------------------------- |
| `⌘ 1`–`⌘ 9` | 选择第 N 个可见工程           |
| `Enter`     | 加载工程 / 变更后重启         |

页面内控件持焦或指针位于 monitor 区域时，表 B 键位由页面处理。投影仅保留原生菜单加速器。演出和投影中的 `Esc` 归页面，创作中展开 monitor 时用 `Esc` 还原工作台。

页面可以监听 `⌘ ←`／`⌘ →`，文本控件保留系统行首／行尾行为。

## 指针与右键

monitor 内容区的指针、滚轮及拖拽事件交给页面。App 抑制原生网页右键菜单，保留页面的 `contextmenu` 事件和可编辑字段的系统剪贴板菜单。

## performer 页

手机浏览器提供真实触屏和多点触控。创作测试窗口的手机视口为 390 × 844 CSS 像素，平板为 820 × 1180，横向交换宽高。切换尺寸保留页面并触发 resize。

测试窗口支持 JavaScript 弹窗和鼠标单点触摸模拟。左键拖动模拟单点，关闭选项后恢复鼠标行为。多点触控、传感器和移动浏览器行为须用实际设备检查。

关闭测试窗口会隐藏页面，从列表删除设备才卸载。连接状态见[演奏端名册](./browser-participation.md#演奏端连接名册)。
