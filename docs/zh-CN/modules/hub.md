# hub 连接与远程节点

`hub` 按需连接既有中继，不默认加入 Blank。工作聊天确认后，在同一任务采用模块、缺少的确切 Socket.IO Node 客户端与生产声明，并完成接线和检查；讨论模式只建议。手动添加模块只复制源码和来源、记录待接线交接。

## 配置与对象

工程声明跨互联网能力后，Host 注入节点、hub 地址、token 和房间配置，字段与范围见[网络契约](../reference/network.md)。凭据不进入页面或日志。

远程节点是远端运行的工程实例；本地手机仍连接本现场 performer。节点数、乐手数与作品角色分别表达。

## 接线与生命周期

完整接口见工程 `modules/pnds-hub/README.md`。工程提供事件、节点摘要展示和需要的作品快照；模块负责连接、重连、心跳、摘要过期和回声过滤，停止时释放连接与计时器。作品进度和声音同步由作者定义。

采用时加入确切 `socket.io-client` 共享引用和生产声明，使用 Host 已校验的 `PNDS_SHARED_LIBRARIES` 入口；缺失或版本错误明确失败，不联网安装。同版资源不重复采用，作者定制不自动覆盖。

## 验证与维护

验证同房事件、不同房间隔离、鉴权拒绝、摘要新鲜度、断线恢复与关停，并检查 hub 不可达时本地演奏仍可用。连接成功不代表声音通过。

任务撤回保留后续独立修改；未保存草稿与磁盘冲突沿工程保护流程处理。模块加入、作品接线、实际运行与听音分别报告。
