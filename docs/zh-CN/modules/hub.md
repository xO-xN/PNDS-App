# hub 连接与远程节点

v1.6.1 提供可选的 `hub` 模块。创作模式的“添加 PNDS 模块”将固定版本源码、`compatibility.json`、双语接线 README 和来源记录加入 `modules/pnds-hub/`，随后生成待接线的创作交接任务。离线添加无需安装 Skill；依赖、配置和接线由外部 agent 按工程实现完成。

## 配置与对象

工程声明跨互联网能力后，Host 按既有配置门注入 `PNDS_NODE_ID`、`PNDS_HUB_URL`、`PNDS_HUB_TOKEN` 和 `PNDS_HUB_ROOM`。room 由工程 id 和分组号派生；不得把示例房间写死，token 不进入页面、日志或交接记录。详细契约见[运行契约](../reference/runtime-contract.md)和[网络](../reference/network.md)。

远程节点是远端正在运行的工程实例，通常对应一处现场的 Mac。本地手机仍连接本现场的 performer 服务。节点数量与作品提供的角色、乐手摘要条数有不同含义。

## 接线与生命周期

以加入目录的 README 和同版本源码公开接口为准。工程提供事件回调、本地摘要、远端摘要展示，以及可选的作品快照适配；事件名、载荷、角色和声音分配由作者决定。技术模块处理连接、重连、心跳、摘要过期和回声过滤，提供可观察状态并在停止时释放连接与计时器。

心跳和摘要过期时限按工程需要配置。不可达、鉴权拒绝、掉线和恢复需要在 monitor 中如实显示；远端失联不能阻塞本地 performer 入场或控制，也不能永久保留已过期的“在线”摘要。模块不裁决作品进度、跨站声音同步或掉线后的演奏方式。

## 验证与维护

分别验证两个节点的同房事件、不同房间隔离、鉴权拒绝、远端摘要新鲜度、断线重连和停止清理；同时验证 hub 不可达时的本地控制。连接成功不等于声音或演出通过，真实设备验收另行记录。

`pnds-module.json` 记录实际加入版本和源文件哈希，复制后源码归工程维护。App 更新不会替换已有内容。已有自定义实现、未知来源、升级、合并或移除交由外部 agent 检查引用、依赖和既有行为；文件加入、接线、实际运行、声音及分发分别记录。
