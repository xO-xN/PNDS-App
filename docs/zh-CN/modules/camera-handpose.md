# 摄像头 HandPose

`camera-handpose` 是按需采用的当前设备摄像头输入。聊天先检查已有可信自带
p5 2.3.2／2.3.4 或共享 p5 2.3.4；缺少时提示“本工程还没有 p5.js”，不加入
ml5、模型或模块，不自动安装或升级 p5。其他作者版本原样保留并明确解决兼容性。
p5 是本模块的产品前提，不表示 ml5 普遍依赖它。一次确认组合采用确切 ml5 1.4.0
和所需模块，在同一任务完成接线、验证、恢复与整任务撤回。

## 离线模型

完整 HandPose lite detector／landmark v1 的模型 JSON、原始权重字节（以文本分片携带）、
来源、Apache-2.0 许可和哈希随工程及 `.pnds` 进入分发。工程的 `assets.js` 先解码
校验哈希，再提供同源模型和权重；缺失或损坏明确失败，不使用 CDN 或运行时下载回退。

## 采集与权限

按钮主动启用，可在系统实际可见范围选择设备／手机前后摄像头。每页一条摄像头流和
一个 Worker 模型链复用关键点与特征；授权、实际出帧、模型就绪和真实推理分别呈现。
普通 LAN HTTP 保留能力限制；拒绝、拔出和失败可主动重试。后台／关页／停用释放本页
资源，迟到结果作废；不会关闭其他页面的输入。投影消费主 monitor 结果，不重复采集。

## 数据

每只手的 21 点 x/y 按提交图像宽高归一化，方向为右／下，非镜像；z 为模型值除图像宽，
缺失为 null，不是校准深度。拇指尖与食指尖距离／腕到中指根距离小于 0.35 为捏合；
四指尖到腕距离均大于对应近端指节距离的 1.2 倍且未捏合为张手。捏合／张手只在状态变化时产生 start/end（失手也结束），按唯一 Left／Right 标签区分，
不随检测数组换序重复触发；Unknown／重复标签只保留连续特征而不新增动作。不是任意手势识别或持续人物追踪。

## 作品接线与验证

助手须把真实采用的特征接到工程校验、接纳资格、公共 action、实际画面或声音状态和
录制回放；示例 `work.js` 用掌位与手势驱动位置／颜色并保存恢复。回放恢复相同效果，
不重新开摄像头；断连期间不积压输入。没有默认录像或原始视频上传。模型计算、真实
采集与真实手部识别分别留证，资源复制不代表完整验收。
