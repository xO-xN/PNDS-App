# 模块手册

逐个讲解 PNDS Template 自带模块的用途与用法，面向基于 Template 创作的创作者。手册随 App 离线分发——排练场、演出机上没有开发环境也能随手查。

术语沿用 App 的统一叫法：座位（代码里是 seat）、claim token（中英文都不译）、performer / monitor（两种页面角色，直接用英文）。

## v1.6.1 离线标准模块

当前 App 提供客户端连接与身份恢复、monitor 主题、monitor 语言、monitor 视图状态、可选 hub、设备运动、设备麦克风及摄像头 HandPose 八个独立条目。通过创作模式添加到 `modules/pnds-<id>/`；每项附带实际源码、双语 README、`compatibility.json` 和 `pnds-module.json`。兼容声明分别列出模块版本、Host 协议、运行依赖与作品适配条件，模块版本不同于 App 版本。接线以已加入目录的同版本 README 为准。

首批旧版来源记录继续可读，App 展示实际已加入版本并保留作者源码和原交接任务。不会自动升级、布线、安装依赖或启动工程。来源不明或文件冲突交给外部 agent；文件存在不代表已接线、已验证或可分发。下文对 Template 独占座位、声道和页面的说明仅描述示例作品策略。投影、诊断与音频仍沿用既有基础设施，不增加为可添加模块。

## 与其他文档的分工

- **[Template 仓库的实现手册](https://github.com/xO-xN/PNDS-Template/blob/main/docs/implementation.md)**（体裁分工）：那边讲模板示例工程本身——示例行为规格、目录职责、「创作时改哪里」；本册是按模块查用法的参考手册，排练与演出时回答「座位怎么持久化」「主题变量有哪些」这类问题。开发机上「从零到发布」的工作流指南是帮助中心的[创作指南](../template-guide.md)，与本册的分工同此。
- **[参考手册](../reference/README.md)**（契约分工）：参考手册面向「工程」这一契约层——manifest、运行时行为、`.pnds` 打包、OSC 等 App 与工程之间的接口；本册面向 Template 自带的模块实现——工程内部这些文件怎么用。契约细节一律以参考手册为准，本册只链接、不重述。

## 刻意不收的模块

- `lib/config.js`、`lib/network.js`、`lib/health.js`、`lib/lifecycle.js`、`lib/osc-transport.js`——基础设施，创作者几乎不需要动；契约见参考手册的 [runtime-contract.md](../reference/runtime-contract.md) 与 [osc.md](../reference/osc.md)。
- `public/performer.js`、`public/monitor.js`——示例作品层：真实作品会把它们整体替换，工作流见创作指南。

## Device motion input

设备运动传感（`device-motion`）是按需能力，通过工作聊天确认后采用，不默认加入 Blank，不依赖 p5 或 ml5。读取当前参与设备自己的倾斜和加速度；不是读取 Host 的设备，也不提供完整陀螺仪。

工程须提供启用、停止、重试与本地化状态。用户按钮直接调用模块 `createDeviceMotion().enable()`；按平台要求申请权限。普通 LAN HTTP 可能被限制；拒绝、API 不可用、等待有效数据和无数据须分别显示，获得权限不等于收到真实样本。后台／关页移除监听、迟到授权失效，返回前台需明确重新启用。主／投影 monitor 只有主副本采集；Client 与 performer 各按自己页面手动启用。

`tilt` 的 beta/gamma 是绕设备 X/Y 轴的角度，范围分别为 ±180°／±90°；不会随横竖屏重映射。`acceleration` 为不含重力的 x/y/z，`gravity` 为含重力的独立字段，单位 m/s²，允许范围 ±200；X 向右、Y 向设备顶部、Z 向屏幕外。0 是真实零，`null` 是缺失，全部缺失不产生有效样本，等待 1.5 秒后显示 no-data。每类最多更新 30 Hz，无平滑与积分；`intervalMs` 是浏览器报告的采样间隔，不是模块发送周期。

同一已批准任务内，助手还须读实际源码，接入页面按钮、固定安全脚本路由、接纳后的服务端 `normalizeMotion` 校验、作者定义的效果及同一公共动作／业务状态／录制回放。先校验归属与资格，再捕获并应用特征；回放恢复相同效果，不申请运动权限，不重复录制。仅发送当前已连接、已接纳的新样本，断线时丢弃，不在恢复连接时突发发送积压。整任务撤回保留作者后续定制。完整接口和限制见加入目录的双语 README。

确定性向量与原生事件替身只能证明计算、生命周期及工程接线。真实手机方向、倾斜与加速度变化、平台权限和浏览器／原生入口须另行实机留证。

## Device microphone input

在工作模式聊天请求采用「设备麦克风」，确认后由同一任务把当前页输入选择、启用、
有效玩家动作、作品状态及录制回放接好。模块不默认加入，不需要 p5/ml5 或音频库。
完整接口见工程 `modules/pnds-device-microphone/README.md`；已有作者源码保留。

每个已启用页面共享一条采集与 Web Audio 分析链，20 Hz 上限输出包络（0–1，
0.8/0.2 RMS 平滑）、峰值（0–1）、1024 点波形（−1–1）与 512 个 FFT 幅度
（−100–0 dBFS；频率 k × sampleRate / 1024 Hz）。这些不是校准声压，也不是无遗漏
连续录音；默认不上传/保存原声或监听扬声器。内置/外接输入只限浏览器实际可见设备。

按钮动作启用，可选择输入、停用并重试；拒绝、不可用、普通 LAN HTTP 受限、拔出
与切换有状态反馈。后台释放，前台不自动开麦；迟到授权立即停止，关窗只清理本页。
投影只读主 monitor 的派生结果。回放使用相同业务状态与特征，不重新请求麦克风。
受控数组只证明计算与接线；手机/外接硬件、系统权限与多窗口共享须另做实机验收。

## Camera HandPose sensor

`camera-handpose` 是按需采用的当前设备摄像头输入。聊天先检查已有可信自带
p5 2.3.2／2.3.4 或共享 p5 2.3.4；缺少时提示“本工程还没有 p5.js”，不加入
ml5、模型或模块，不自动安装或升级 p5。其他作者版本原样保留并明确解决兼容性。
p5 是本模块的产品前提，不表示 ml5 普遍依赖它。一次确认组合采用确切 ml5 1.4.0
和所需模块，在同一任务完成接线、验证、恢复与整任务撤回。

完整 HandPose lite detector／landmark v1 的模型 JSON、原始权重字节（以文本分片携带）、
来源、Apache-2.0 许可和哈希随工程及 `.pnds` 进入分发。工程的 `assets.js` 先解码
校验哈希，再提供同源模型和权重；缺失或损坏明确失败，不使用 CDN 或运行时下载回退。

按钮主动启用，可在系统实际可见范围选择设备／手机前后摄像头。每页一条摄像头流和
一个 Worker 模型链复用关键点与特征；授权、实际出帧、模型就绪和真实推理分别呈现。
普通 LAN HTTP 保留能力限制；拒绝、拔出和失败可主动重试。后台／关页／停用释放本页
资源，迟到结果作废；不会关闭其他页面的输入。投影消费主 monitor 结果，不重复采集。

每只手的 21 点 x/y 按提交图像宽高归一化，方向为右／下，非镜像；z 为模型值除图像宽，
缺失为 null，不是校准深度。拇指尖与食指尖距离／腕到中指根距离小于 0.35 为捏合；
四指尖到腕距离均大于对应近端指节距离的 1.2 倍且未捏合为张手。捏合／张手只在状态变化时产生 start/end（失手也结束），按唯一 Left／Right 标签区分，
不随检测数组换序重复触发；Unknown／重复标签只保留连续特征而不新增动作。不是任意手势识别或持续人物追踪。

助手须把真实采用的特征接到工程校验、接纳资格、公共 action、实际画面或声音状态和
录制回放；示例 `work.js` 用掌位与手势驱动位置／颜色并保存恢复。回放恢复相同效果，
不重新开摄像头；断连期间不积压输入。没有默认录像或原始视频上传。模型计算、真实
采集与真实手部识别分别留证，资源复制不代表完整验收。
