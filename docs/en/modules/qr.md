# QR Code

The App provides QR, not an addable project module. Open the bottom network popover to view the invitation, copy its URL or scan:

- **Performance mode**: the Host's public performance entry; it waits when idle and participants explicitly enter the current performance.
- **Creation mode**: the current ready test's actual performer URL, joining that test directly; expanded monitor uses the same entry.

## Invitations and valid state

The public performance entry is managed separately from the internal performer port. Creation QR must match the current project and ready test. After stop, restart, switching or entry failure, obtain the address from actual state. Complete URLs retain scheme, host, port, path and query; HTTPS failure is explicit without an HTTP fallback.

Invitation actions do not refresh the project, change sound or alter projection introduction/start state. A QR grants no access to a later performance; entry and confirmation follow the [runtime contract](../reference/browser-participation.md#browser-participation-protocol-1).
