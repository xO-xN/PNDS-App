# 底栏液态玻璃按钮：设计与评审说明

初稿：2026-10-24；本轮增量：2026-10-25。原型：[liquid-glass-actions.html](./liquid-glass-actions.html)。

当前决定是恢复上一版玻璃与文字，只移植新彩虹边框效果。独立 HTML 的 C 方案将彩虹像素经过 SVG 内容折射，再裁成单条细环；原生文字不加滤镜、不作位置补偿。用户随后批准将该彩边接入正式 App，当前由 `DesktopActionGlass`／`desktop-controls.css` 与 `liquid-glass-rim.ts` 提供；原玻璃主体、文字、交互及 Brutal 保持不变，生产规则见 [UI 模式](../developer/ui-patterns.md#两种模式共用底栏与按钮材质2026-10-25)。下文历史原型验证不代替生产验收。

## 三种光学方案

| 方案                 | 色场与玻璃关系                                 | 评审重点                                   |
| -------------------- | ---------------------------------------------- | ------------------------------------------ |
| A · 三色光流（对照） | 三种颜色在透明镜片背后缓慢交融                 | 保留最初完整色场与通用反射                 |
| B · 底部色带（对照） | 将色场集中到按钮下半部                         | 保留色带与通用反射对照                     |
| C · 新版彩边（当前） | 彩虹像素折射后裁成单环，位于原玻璃前的周边区域 | 原玻璃和清晰文字不变，仅比较新版／旧版彩边 |

C 默认开启“新版彩边”。关闭开关，或使用 `optics=off`，可对比上一版细环；开关不改变工程选择、运行或模式状态。两种彩边均只有一条可见环，厚 1.1px、内缩 1px，保留鲜艳七色与 5 秒线性循环。C 的原镜像 refraction 继续隐藏，不恢复 edge-glow、soft-fill 或整面彩虹填充。Brutal 不启用新版彩边，仍使用纯色方角和原斜切矩形滑动，确认文字保持静态主题色。

左右按钮保持 30px 原尺寸：左侧宽 100px，模式按钮宽 164px，窄桌面沿用 150px 槽位。评审控件可将按钮放大到 1.7 倍观察细节，再恢复原尺寸；放大时的 90px 底栏只是检视辅助，不是正式布局提案。正文、工程与设备均为合成示例，创作主体仅作占位，不据其尺寸修改正式工作台。

## 状态与交互

- **已选工程：** 加载按钮开启当前方案的色光；C 只更新彩边像素，按钮中心仍是原版玻璃和原生文字。选卡只改变选择，不启动工程。
- **运行中：** 关闭按钮撤去彩虹并停止流动，降低静止强调；悬停或键盘聚焦才显出危险色。它仍表示关闭，不表示暂停。
- **模式悬停／确认：** 非 Brutal 的模式按钮在 idle 时，悬停按钮本身或出现键盘 `focus-visible` 即发光。首次点击保留原中性玻璃提亮与阴影，确认文案继续使用 0.8px 逐字波浪和低饱和字色循环，不加内容滤镜或额外位移。第二次点击才切换，Escape、外部点击或窗口失焦取消。普通说明浮层保持移除，完整名称与描述仍提供给读屏。Brutal 保留原 44px 斜切、300ms 矩形滑动和文字位移。
- **运行 A、选中 B：** Monitor 继续显示 A，选中 B 只重新强调加载；点击后先具名确认替换，取消保留 A。模式切换接续运行中的 A，不把选择 B 当成运行 B。
- **未选／加载进行中：** 不可加载状态禁用按钮并关闭色场；演示计时器完成前阻止重复动作。切换预设场景会重置内存状态和计时器。

这些交互只演示视觉状态。真实 App 的草稿保护、运行继承、权限、异步归属及启动／关闭流程仍由正式业务负责；合成 Monitor 的画面连续也不证明真实 iframe 的挂载、音频或演奏者连接已通过验收。音量滑块只修改示例数字，音频、网络、设置和投影摘要不连接系统功能。

## 实现边界与公开参考

HTML 内联 [Liquid Glass v1.0.0 核心引擎](https://github.com/gentpan/liquidglass/blob/main/lib/liquid-glass.js)，保留 gentpan 的 MIT 版权和许可。只使用 `createGlass` 的 content 模式处理彩虹像素：普通 CSS `filter` 引用 SVG 位移贴图；不使用仅 Chromium 能完成此用途的 `backdrop-filter: url()`，也没有直接引入附带指针跟随交互的 `lg-lens` 自定义元素。引擎包含 WebKit 的坐标比例、贴图解码和滤镜缓存处理；跨引擎实机表现仍需验收，不能从库的支持说明推定本原型已经通过。

参考标本为 `width=360`、`height=160`、`radius=137`、`refraction=60`。为保持既有按钮布局，以实际 30px 高度除以 160 适配像素参数：传入圆角 25.6875px，再由引擎限制到半高 15px；折射距离为 11.25px。`width`／`height` 通过 `fit` 跟随实际按钮。其余参数保持 `bezel=1`、`curvature=2.5`、`chroma=0.12`、`blur=0`、`specular=0.25`。这些参数现在仅作用于彩虹边框，不处理玻璃主体或文字；评审区显示参考值与有效值，不宣称 30px 按钮使用 60px 的实际像素位移。

每个 C 按钮只有一个内容折射 pass：完整七色光谱位于 `.refracted-spectrum` 中，滤镜输出最后经过原 1.1px 单环遮罩，避免先裁成细环后被穹顶采样带走。启用时 `.colour-field` 位于 `z-index:3` 的周边层，只有遮罩留下的细环显示在原玻璃前，中心完全镂空，不覆盖文字。彩虹像素经过折射，外轮廓仍由固定细环遮罩决定；没有第二条彩环，也没有整面彩虹填充。

彩虹采样层使用已知的 `--bar` 不透明底色，使三通道色散合成有稳定的 alpha；其最终可见范围仍仅是细环，不是对任意页面背景的透明采样。上层整面 `.optical-lens`、文字副本及文字滤镜已经删除。原版镜片、原生文字位置、焦点、禁用、名称和事件处理保持不变；既有确认文字的 `2.6s` 波浪、`-0.8px` 波峰、`scaleY(1.025)` 与 `4.8s` 柔和彩虹周期保留。

关闭“新版彩边”、切换 A／B 或 Brutal、进入减少透明度／提高对比度／强制颜色偏好时，销毁边框滤镜并把同一个光流节点放回原细环，使用原视觉及系统回退。无法建立 canvas／滤镜时也保留旧彩边。减少动态效果隐藏彩虹层并停止文字与光流动画，不留下静态红角。页面隐藏时暂停装饰动画，非缓存卸载时销毁滤镜与观察器。

本原型没有 WebGL 管线，不捕获页面或 Monitor，不读取作品画面像素。代码、位移贴图生成逻辑、样式和合成数据都在单个 HTML 内，无必须的外部运行资源或 npm 依赖；不调用 Tauri，不访问工程文件、偏好存储、真实设备或运行服务。

## 2026-10-25 第二轮：玻璃背后薄环与统一 8 秒交互（历史）

以下记录模式确认仍为薄环、Brutal 仍只用实色确认的第二轮实现与验收；当前已继续调整为下节的整面彩虹和 Brutal 斜切动画。

C 继续作为该轮基础，A／B 保留对照。源彩虹环改为 1.1px，向内偏移 1px；同色场的反射副本为 0.8px、强度 0.38，并作水平镜像和纵向轻压缩。源环与副本实际移到 button 前的同级层，均以 `z-index: -1` 位于透明镜片后，外侧保留较弱柔光。镜片以低模糊呈现局部光学层次，文字不加滤镜；这不等于真实背景采样或物理折射，也不读取 Monitor。

非 Brutal 的加载与模式光效都使用 8 秒循环。模式 idle 时通过 `:has(> .lens:is(:hover, :focus-visible):not(:disabled))` 判断按钮本身，悬停或键盘聚焦即亮，不因移动到说明区而启动，也不受旧 `data-paused` 门禁约束；该标记仍只控制模式文案在切换完成后的立即翻转。发光不代表动作已准备：首次点击才进入 armed，第二次点击才提交，原 Escape／外点／失焦取消逻辑不变。
