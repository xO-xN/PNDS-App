# v1.6 / v1.7 UI 交互原型

状态：UI 已由用户定稿（2026-10-03），以当前 A（并排工作台）和第八轮交互为实现基线；B / C 保留为比较记录，不作为本轮发布要求。入口为 [pnds-ui-prototype.html](./pnds-ui-prototype.html)。字体与图标引用仓库已有资源，保留当前目录位置即可。建议通过本地 HTTP 预览，使独立 Performer 窗口能够与主界面通信。

正式版本规格：[v1.6.0 演出与创作模式](../plans/v1.6.0-creation-mode-spec.md)、[v1.7.0 创作助手](../plans/v1.7.0-creation-assistant-spec.md)。下方各轮是讨论记录，后续轮次覆盖前面的同项设计。

发布范围补充：后续决策已确认 v1.6.0 实现首批五项标准模块的真实文件添加、来源记录和外部 agent 接线交接；v1.6.1 整理模块接口、文档、兼容、可选 hub 模块及外部 Skills，见[正式规格](../plans/v1.6.1-modules-skills-spec.md)。v1.7 助手只按需提示用途与安装步骤，Skills 自愿安装，App 不执行安装或移植。原型模块文件与任务仍是内存演示，不能充当正式源码、接线状态或实际验证结果。原型在切换工程时清空聊天仅为内存演示；v1.7.0 的真实聊天记录按工程在本机持久化，重新打开工程恢复对应记录。

## 比较方式

- 底部切换 A（并排工作台）、B（预览优先）、C（上下工作台）；URL 支持 `?variant=A`、`?variant=B`、`?variant=C`。
- `v1.6` 展示两种模式与创作工作台，`v1.7` 增加创作助手。
- 支持 Pond、Sand、Stage、Brutal 四种现有主题。
- “演示状态”可直接打开工作台，或查看外部更新、保存冲突、缺少依赖、空白工程等状态。
- “查看状态”展示内存中的工程、运行、未保存、待更新和助手状态。

## 第二轮调整

- 保留原版左侧栏，移除 App 顶部栏和其中的 Logo。红绿灯在侧栏顶部预留原生窗口按钮的位置；HTML 中仍是位置示意。
- 模式切换固定在侧栏底部，两种模式始终经过确认。
- 模块分类标题内提供添加入口；下拉菜单和音量推子参考现有 App 的细节。
- Monitor 始终保留在预览区。Performer 使用[独立测试窗口](./pnds-performer-prototype.html)，支持手机 / 平板和横屏 / 竖屏，交互可以反馈到主界面的 Monitor。浏览器可能将弹出窗口显示为新标签页，实际 App 将使用独立窗口。
- v1.7 创作助手作为中间编辑区的标签页打开，可与文件标签切换，不覆盖 Monitor。

## 第三轮调整

- 侧栏底部使用显示当前模式的单一菜单按钮；移除重复的模式状态行和「演出内容」标题。
- 编辑区只保留当前选中文件和 v1.7 创作助手两个入口，移除工具栏的重复助手按钮；切换文件保留内存中的未保存内容。
- Performer 区显示各测试窗口的编号、设备方向和连接状态。下方「＋」可添加多个窗口，点击编号显示对应窗口，关闭按钮只关闭该窗口。
- Monitor 右上角提供全屏预览按钮，在当前 App 工作区暂时隐藏侧栏、编辑区和窗口列表；点击退出按钮或按 Esc 还原，不改变工程运行及测试窗口。

## 第四轮调整

- 演出卡恢复原版的单一满宽按钮：加载 / 更改 / 关闭。移除额外停止按钮和重复的运行作品状态行。
- 运行中的 Monitor 占满 App，不再有上下控制栏；侧栏覆盖 Monitor，指针移到左边缘或按住 Cmd 显示，离开后自动收起。侧栏显隐不改变 Monitor 尺寸，也不刷新页面；操作下拉菜单和对话框时保持显示。场地屏与刷新入口移回侧栏上缘。
- 模式按钮默认只显示当前模式；悬浮或键盘聚焦时，右侧显现另一模式的彩色入口。首次点击在按钮内提示再次点击，并说明停止运行或放弃未保存内容的后果；再次点击结束当前运行、关闭测试窗口并进入另一模式首页。Esc、点击其他位置或失去窗口焦点可取消，不弹出切换对话框。
- 中间区域依次为当前文件、控制台、v1.7 创作助手。控制台展示工程运行日志，移除右上角日志按钮和浮动日志小窗。切换页面保留文件草稿。
- 实时测试标题旁新增 Internal / External / None 音频选择，仅允许工程声明支持的模式。External 显示单独的 App 测试 OSC 目标，不读取 manifest 的 standaloneTarget。修改测试配置后提示手动启动 / 重启，运行状态保持显示已应用配置；该选择不修改工程默认模式。

## 第五轮调整

- 模式切换按用户示意图采用胶囊轮廓与斜切色块：浅色演出、悬浮切换提示、首次点击的「再次点击切换」、深色创作。反向使用相反的色块变化。提供键盘聚焦反馈与减少动态效果支持，确认后果放在胶囊下方，不弹窗。
- 演出→创作时，可编辑文件夹工程直接进入同一工程工作台并复用当前运行和已应用音频模式，无需重新选择或启动。以正在运行的工程为准；没有运行时可打开已选文件夹，但不启动测试。启动中的短暂状态禁用模式切换，避免未完成的启动交接。
- `.pnds` 与内置工具不进入编辑，切换后进入创作首页并结束旧运行。创作→演出始终结束测试、关闭测试窗口，回到演出首页，不自动载入。
- 创作侧栏工程标题在悬浮 / 聚焦时显示「切换其他工程」。选择器新增另一文件夹工程；取消选择或取消未保存确认都保留当前工程。切换确认前不关闭旧测试，确认后清空旧工程的文件草稿、助手聊天和授权、待办、错误与交互状态；模型服务配置保留。
- 此轮演出→创作的接续覆盖此前的双向结束运行方案；整理 spec 时应同步更新版本规划草案与 ADR-0007。

## 第六轮调整

- 模式按钮使用现有 App 的控件底色、主题强调色与文字色。斜切边缘上下始终相差 56px，悬浮与确认过程只平移，不改变斜率；确认文案靠右落在目标色块内。Brutal 跟随其直角、硬阴影与无过渡风格。
- 工程选择器新增「新建空白工程」，复用作品信息与保存位置表单。取消表单保留旧工程；有未保存内容时，在确认创建后再提示放弃修改，确认前不结束旧测试。
- 助手工程概况默认只显示一行标题与新鲜度，悬浮时展开、离开后收起；键盘聚焦也能展开，失焦后收起。
- 网络与节点页补齐现有 App 的节点名、Hub 地址、遮罩 Token 和网络地址，采用左标签、右控件布局。编辑后提示下次启动生效，演示值在原型内存中保留；Token 不进入状态展示或日志，不发起连接或写入偏好。

## 第七轮调整

- 切换模式后立即显示新模式的静止样式；指针仍停留在按钮上时不显示目标模式提示，移开后再进入才恢复悬浮效果。键盘聚焦仍提供确认与取消操作。
- 收紧侧栏上缘，模式按钮下移到距底部 12px；确认后果只在首次点击时出现，放在按钮上方。移除帮助按钮、演出卡重复的所选工程标题与名称。
- 演出文件夹改为下拉选择，内置多个独立编组并可新建更多编组。工具使用随时可切换的独立按钮，再次点击返回上一个用户文件夹。编组切换只影响浏览列表，保留当前运行作品与音频；打开工程会将它加入当前用户编组。
- 工程文件栏移除新建文件与导入素材入口，改为单一 Finder 按钮，展示当前工程文件夹路径的演示反馈；移除文件删除按钮。继续保留现有文件阅读、封面编辑、保存与外部 agent 交接流程。
- 移除文件树底部的类别说明与固定 Skills 安装入口，保留文件类别色彩与 PNDS / 作品标记。创作助手在首次讨论外部 agent 实现时给出一次 Skills 安装提醒；询问 Skills 安装时也可获得仓库入口。
- 多文件夹数量与成员仍是原型内存状态；后续 spec 需同步解除实际 App 中原有的文件夹数量限制。

## 第八轮调整（当前）

- 第二次点击模式按钮后，斜切色块沿原来的固定角度平移至整个按钮，目标模式名称随之淡入；300ms 结束后显示新模式静止样式，继续保留“移开再悬浮”的规则。过渡期间禁用重复点击，保持按钮不透明；减少动态效果与 Brutal 主题直接完成。
- 工具按钮点亮时隐藏用户文件夹下拉，原位置显示「返回＋上一个文件夹名称」。点击返回入口或再次点击工具，恢复此前的文件夹与下拉；列表切换继续保留当前运行。
- Creator Monitor 顶栏明确显示「创作模式」，包含展开后的全屏预览。
- 设置恢复 Ports 调试页：Performer / Monitor 端口、进入时查询一次、手动刷新、可用 / 外部占用 / 当前运行工程状态。外部进程显示 PID、名称与完整命令行，释放前重复确认身份；运行工程端口引导先关闭工程。底部演示状态新增「端口被外部进程占用」，用于核对确认与释放流程。
- 查看 `.scd` 时，当前文件工具栏提供「编译 SynthDef」，范围为本工程的 `supercollider/source/*.scd`。未保存的 SCD 或 manifest 会禁用编译；按钮展示编译中，成功与错误进入控制台。成功后列出 `.scsyndef` 产物、核对所有 manifest 引用并标记待重启，不自动更新运行版本。源码示例改用 `.add` 注册 SynthDef。
- Ports 查询 / 释放和 SynthDef 编译均为内存演示，不查询真实端口、不结束系统进程、不调用 sclang、不写产物。

## 建议核对的流程

1. 演出模式选择作品、加载，核对单一按钮的更改 / 关闭状态；离开侧栏看全窗口 Monitor，再移到左边缘显示侧栏。
2. 悬浮模式按钮，核对斜切色块、两次点击确认及取消，以及切换后指针停留时的新模式静止样式；文件夹工程直接进入同一工程创作，工程包进入创作首页。切回演出模式应回到开始界面。
3. 编辑源码或 README，保存后核对手动刷新 / 重启提示；添加多个 Performer 测试窗口，核对手机 / 平板、横屏 / 竖屏、各窗口状态和它对 Monitor 的互动；核对 Monitor 全屏预览及返回。
4. 悬浮工程标题并切换到另一文件夹，核对取消与未保存确认；查看 manifest 表单、音频素材的 Finder 入口、模块添加与交接任务、控制台第二页、测试音频切换、生成 `.pnds` 的保存位置。
5. 切换 v1.7，使用演示 API 配置，核对工程概况、第一次发送工程内容的确认、来源清单、建议转交外部 agent 的任务与聊天中的 Skills 提醒。
6. 新建演出文件夹，打开工程加入其中；核对编组成员独立、工具视图隐藏下拉及返回入口，以及列表切换不影响运行中的 Monitor。
7. 查看 SCD 工具栏编译入口与控制台结果，核对未保存保护和待重启提示；在设置查看 Ports 调试，使用外部占用演示核对释放确认，再在运行中核对端口保护。

## 原型边界

所有工程、文件、运行、保存对话框和助手回复都是本地演示。原型不读写用户工程，不启动音频或工程服务器，不打开 Finder，不调用模型 API，不存储密钥。刷新浏览器会重置状态。

空间分配、信息层次与关键操作已经定稿；开发验收以正式版本规格为准，原型用于视觉和交互对照，不代表真实运行能力已经实现。
