PNDS 创作指南 · 拟更新文案

从想法到实现

有了想法，先在 PNDS 创作助手的“讨论”模式中商量实现方式。助手会结合工程现状，只追问影响方案的关键问题；你可以随时补充、修改目标。

谈清方案后，选择如何实现

  1. 交给外部编程智能体：选择“写交接文件”，审阅和修改草稿，再点击“记录交接”。将工程交给外部编程智能体，让它阅读 docs/creator-handoff.md 后接续工作。
  2. 交给内置助手：核对回复中的目标、范围与验收，点击“开始工作”。助手立即切换到“工作”模式，按已确认方案实施。输入框下方会同步选中“工作”。

你也可以直接切换到“工作”并发送明确任务。仅切换模式不会启动工作；讨论中的回答用于澄清方案。

整理工程，用一句话提出

帮我整理一下工程代码库，保留现有声音、视觉与演奏交互。

助手也会在发现结构或重复代码妨碍继续创作时，询问是否整理。先说清范围，再按你的选择开始工作。

明确发送“帮我整理一下工程代码库”，会直接切到“工作”并开始整理；如果只是助手提出整理建议，则等你选择后才开始。

有补充规范时，把要求写在消息里，或指定一份工程文档／创作资料，例如“按这份规范整理，保留现有目录”。遇到会改变作品行为的冲突，先讨论决定。

实现后核对实际结果

核对修改内容，运行工程检查，再进行实际音画与演奏交互测试。需要保留一个创作节点时，保存工程版本。

保存与命名工程版本

默认名称沿当前工程版本的名称系列递增，如“呼吸 → 呼吸 1 → 呼吸 2”。从旧版本继续时跳过已用序号。查看历史版本不会改变续号起点。

版本保存后仍可改显示名称，内容与版本关系保持不变。只改选中版本；当前版本改为“流动”后，下次默认“流动 1”。
