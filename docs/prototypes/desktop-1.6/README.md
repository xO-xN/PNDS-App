## 已确认的设计

- macOS 专业创作／演出工具：系统字体、紧凑排版、中性底色、克制的圆角与强调色；Pond、Sand、Stage、Brutal 四主题保留，布局和控件结构统一。
- 无 App 顶部栏、顶部 PNDS 字样或侧栏 toggle。macOS 红绿灯位于侧栏顶行，该行没有三点按钮；真实 App 应使用原生窗口按钮，HTML 仅示意位置。
- 演出侧栏是 Zen 风格悬浮圆角矩形。准备时常驻，运行时自动隐藏；靠左悬停或按住 ⌘ 唤出，离开收回，菜单与操作期间保持可见，不挤压或重载 Monitor。
- 加载／关闭、刷新、音量、音频设备与采样率、网络、投影、设置集中在底部。浏览作品 B 时，音量仍控制运行中的 A。应用配置与待应用配置明确区分，调整设备等设置不静默重启。
- 模式切换固定右下角，保留同一位置两次点击确认和现有斜切动画。普通切换不显示额外解释，仅涉及未保存内容损失时在按钮上方提示。运行接续与草稿清理规则见正式文档。
- 演出不提供 Audio mode 选择，按工程声明的默认模式启动；创作测试区继续提供工程支持的 Internal／External／None。不要删除底层模式能力。
- 创作侧栏突出 manifest 与 README；其余结构文件按运行与依赖、页面、声音、编译产物、模块、资源、工程支持分组，保留实际路径及源文件／产物区别。
- 控制台默认关闭，只在创作模式有入口和快捷键；演出错误仍保留可操作的错误与诊断入口。
- 全局设置使用分类导航，保留现有音频、网络与节点、HTTPS／DNS、端口等能力。打包和交接位于创作工程标题下拉；演出保留一个三点菜单，所选作品操作收在其中。

## 实现与验收

原型只模拟内存工程、文件编辑、运行、独立 Performer 与投影窗口，不连接真实音频、磁盘、服务器或偏好。示例路径、作品内容、地址、日志、错误与端口状态均不能作为生产数据或接口实现依据。「原型」菜单、场景切换、模拟运行画面不进入 App。

实现时先盘点实际仓库与 #163 后功能，映射现有组件、状态与命令，再按此基线改 UI；避免照搬原型的单文件状态或用重建 DOM／webview 实现模式切换。真实 Monitor 实例、测试窗口、异步启动／关停及已应用配置的生命周期必须保留。

原型验证：`node --test docs/prototypes/desktop-1.6/prototype.test.mjs`。仓库完成标准：`npm run check:all`。浏览器已核对常规和窄桌面布局、自动显隐、原位模式确认及控制台隔离；真实 macOS 红绿灯、拖动区域、全屏、键盘和音频仍须在 App 实现阶段验收。

本目录的 [SHA256SUMS](./SHA256SUMS) 标记本次定稿文件，使用 `cd docs/prototypes/desktop-1.6 && shasum -a 256 -c SHA256SUMS` 核对。若用户以后明确修改设计，应记录新修订，不静默覆盖本次基线。
