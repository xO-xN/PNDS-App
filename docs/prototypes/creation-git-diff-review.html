Git 文件差异 · 待核对方案

本原型仅核对文件导航、比较方向和阅读方式。所有版本与代码均为合成示例，不读取或修改真实 runes-pnds，不启动测试。

  1. 保存反馈：去掉常驻“本地版本已记录”回执；保存后短暂提示，并在图中定位新版本。必要的保存警告仍单独呈现。
  2. 左侧联动：在 Git 页，左栏明确标为“对比文件”。单击直接查看差异，保留 Git 页；离开 Git 后恢复当前工程文件。删除文件也可查看，不会伪装成当前存在的文件。
  3. 比较方向：默认“上一个版本 → 选中版本”，呈现此版本带来的改动；可切到“选中版本 → 当前保存文件”。当前未记录修改与 HEAD 比较，编辑器草稿不计入。
  4. 代码：删除为红色与 −，添加为绿色与 +；有行号、整行底色、局部变化加深、上下文展开、上一处／下一处跳转、逐行／左右对比。
  5. 打开文件：明确点击“打开当前文件”才进入文件页签；这不等于载入历史内容、不切换代码版本，原有草稿保护不变。
  6. 三个布局：A 保留横向版本图、代码占主要空间；B 将图移到中间栏左边，增加代码高度；C 默认折叠图，连续查看所有差异，左栏用于定位。
  7. 底栏：启动／重启按钮按内容占宽，紧接音量；取消音量两侧竖线，刷新仍在原生“窗口”菜单。

原型中的完整版本文件差异、父版本对比和逐行渲染是拟议能力，需在正式实现中补齐原生读取契约与大文件限制；不是对现有 App 能力的验收结论。
