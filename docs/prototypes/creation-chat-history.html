聊天历史怎么放

A 会话栏 把历史列表、搜索和新聊天放在讨论区左侧。可以边读边切换，收起后把宽度还给消息。

B 聊天标签 最近四个打开的聊天可以直接切换。全部历史和删除操作在独立的管理面板里。

C 历史面板 平时只显示当前聊天和独立的新建入口。历史集中在可搜索面板里，保留讨论区宽度。

三个布局复用同一组内存示例。刷新恢复数据。聊天标题取第一条问题；重命名和置顶可后续评估，需先决定保存格式和排序。
