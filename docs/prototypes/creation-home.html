创作首页的设计取舍

三个方案把工程选择放在窗口中央。点击工程会进入模拟工作台。打开、新建、克隆和移除历史都使用示例数据。

A · 居中列表
打开、新建和最近工程同屏。适合作为默认首页，首轮可直接复用现有工程路径和顺序。历史较长时先显示四项，可展开全部。
B · 继续创作
给上次打开的工程一块显眼的封面，其他工程列在右侧。适合反复回到同一件作品的创作者。正式接入可读取已有封面，缺失时使用主题底图。
C · 快速打开
工程名与路径统一搜索，支持方向键和回车。适合历史较多或常用键盘的创作者。左、右切换方案时，输入框仍保留光标操作。

可以继续探索

固定常用工程
独立于打开顺序保存常用项。需要持久化的固定项目及排序规则。
首次创作引导
把「新建 Blank」和「打开已有工程」做成两个明确选项。可在首次使用场景评估帮助入口。
工程库检索
后续把已知文件夹工程和最近创作合并检索。需先核对可编辑性，并为失效路径和只读工程设计反馈。
