## 比较方案

| 方案          | 反馈位置与复用关系                                                                                                                                                                                             |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A：按钮旁状态 | 操作按钮立即显示进行中文案与小转圈，同一页面保留阶段、结果及重试入口；适合保存、切换等当前页面操作。                                                                                                           |
| B：持续通知   | 重现现有 `notifications.flow` 的通知样式：30px 图标格、14px 圆角，通知位于 App 外框内右下方、底部偏移 64px，在 50px 底栏上方；同一通知从进行中原位更新为成功或失败。正式进行中提示不提供「关闭通知」操作按钮。 |
| C：页内细进度 | 新增样式提案，在页面内的固定反馈位置加入 3px 细进度条，保持原有工作区密度；是否采用仍待用户选择。                                                                                                              |

三种方案沿用当前系统字体及 Pond、Sand、Stage、Brutal 四主题，直接读取真实 `src/theme-variables.css` 配色。Brutal 保留方角、硬边框及硬阴影；减少动态效果时停用转圈和流动动画，进行中状态文字仍可见。B 的视觉参照是现有通知，HTML 本身不调用 Sonner 或 App API；真实通知流程见 [notifications.md](../developer/notifications.md#flow-toasts-progress--outcome-in-one-place)。

HTML 中的旧关闭通知演示尚未同步本次撤回，保留为历史对照，不作为正式 App 的进行中入口。正式结果提示继续沿用 Sonner 原有右上角关闭按钮及自动消失规则，真实的刷新、重试及 Releases 操作保持可用。

## 场景与计量

| `scene`   | 演示操作                   | 进度含义                                                                         |
| --------- | -------------------------- | -------------------------------------------------------------------------------- |
| `save`    | 保存 runes 最新改动到 main | 保存文件、检查改动、创建版本、刷新列表；使用不定进度，不生成百分比。             |
| `switch`  | 切换版本                   | 保存文件、停止测试、切换版本、同步文件；使用不定进度。                           |
| `install` | 安装 `.pnds` 工程包        | 验证、解包、读取工程；使用不定进度。                                             |
| `import`  | 导入演出文件夹             | 显示当前工程及已完成／总工程数；C 按工程数量计量，不代表字节数或剩余时间。       |
| `record`  | 保存演奏记录当前轮次       | 整理记录、保存轮次；使用不定进度，不替换实际录制／回放计时。                     |
| `dns`     | 启用 DNS 服务              | 启用及读取状态；使用不定进度，不代表已经获得真实系统授权。                       |
| `update`  | 手动检查更新               | 仅检查及反馈结果；使用不定进度，没有 App 内下载或安装阶段。                      |
| `handoff` | 采集交接文件               | 显示当前文件已读取字节及已读取文件数；当前文件的进度条不是整个交接流程的百分比。 |

所有耗时、阶段、文件、计数、字节数和错误都是内存模拟。现有后端没有提供的阶段或计量，不能因 HTML 能演示就认定已经可在 App 中使用。正式接入时须以真实操作边界更新反馈，不用计时器推算百分比。

保存场景单独保留“已保存”事实：创建版本完成后进入“正在刷新版本列表…”。此时模拟失败会显示“版本已保存，列表刷新失败”，重试入口为“刷新列表”，只重试刷新，不重新保存版本。这一结果区分在 A／B／C 中保持一致。

## 操作与参数

`variant=A|B|C`、`scene=save|switch|install|import|record|dns|update|handoff`、`theme=pond|sand|stage|brutal`、`lang=zh-CN|en` 指定初始方案、场景、主题和语言。无参数时为 A、保存版本、Pond、中文。

App 外框下方的控制区用于评审，不属于产品。底部方案按钮、前后箭头或左右方向键切换 A／B／C；输入、选择框和按钮持焦时不接管方向键。方案、主题和语言切换保留当前演示状态，切换场景或重置会停止旧计时器并载入初始样例。操作按钮在进行中禁用，避免重复发起同一演示。

演示速度提供“正常”“慢速”“保持等待”。正常与慢速自动推进；保持等待停留在当前进度，便于观察较长等待时的样式。“暂停演示／继续演示”“完成”“模拟失败”“重置”只控制原型，不能据此增加正式操作的暂停、取消或强制完成能力。B 的关闭通知后继续运行仅为上述历史演示；保存场景可在进入刷新阶段后模拟失败，再核对仅刷新列表的恢复路径。

英文文案源为 `locales/prototype-operation-feedback.en.json`，中文镜像为 `locales/prototype-operation-feedback.zh-CN.json`，两者键集合保持一致。运行 `npm run prototype:locales` 将英文源同步到 HTML 的 `prototype-translations` 数据块；内嵌数据支持直接打开本地 HTML，不通过 fetch 读取文案。数据块为生成结果，不手动维护。工程名称、版本名称、路径及文件内容不随界面语言改写。
