## 第二轮精简（2026-10-24）

音频／网络的完整设置与快捷面板改成单层字段：移除顶部设备、采样率、地址与节点摘要卡，也移除重复的“下次启动”标题和自动保存说明。正常状态下每个值只出现一次，可直接选择或编辑；顶部只保留运行状态与模式／协议等没有重复的上下文。

仅当正在运行且配置有差异时，在相应字段下显示“当前仍用 …”，并集中提示下次启动生效。重新采用后，差异自动消失。系统默认保留选择策略并用演示默认设备解析显示；External 不显示 App 设备／采样率的当前差异或通道损失，未运行时不展示当前运行对比。

复制入口移到本机地址行末，取启动时记录的 `applied.performerUrl`；编辑 LAN 不改变所复制的运行入口，未启动时按钮禁用。模型和 Git 身份页也删除仅重复页面标题或用途的展示卡。A/B/C 与四主题沿用这一精简结构。

## 状态与交互边界

当前运行 `applied` 与下次启动 `preferences` 独立。设备、采样率、LAN、OSC、节点和 Hub 输入只更新待应用示例；不静默停止、启动或重载演出。演示中的明确重新启动才可采用下一份配置，选择另一布局或主题不重置这些值。

主示例为 Internal、8ch：主音量固定 100%，音量滑杆与静音不可操作；切换设备不会把它误画为普通立体声音量。设备清单显示通道能力，2ch 设备对应明确的 8ch → 2ch 警告。演出模式不新增 Internal／External／None 切换，工程声明与实际运行模式分别呈现。OSC、Room 在外部音频／远程演示场景出现；HTTPS 在完整设置中展示准备流程；Hub Token 留在完整节点设置并遮罩。

DNS 单独表达服务操作：真实启用涉及系统后台服务注册和 macOS 授权，不属于“下次启动演出”配置。原型只切换未启用与待系统授权，刷新不推进到运行成功；不发起系统调用。DNS 状态不等于路由器或演奏者设备已配置成功。

快捷面板与完整设置共享同一份内存输入。菜单、面板与详情应能通过键盘操作，Escape 关闭后返回原入口；错误保留可读原因，不能只改变状态点颜色。关闭设置不清空尚在演示中的输入，页面刷新才重置原型。

## A 方案接入（2026-10-24）

底栏网络恢复节点名称，Hub 地址和遮罩 Token 留在完整节点设置。正式设置窗口采用 A 的分组图标导航、分类关键词搜索和四主题预览；音频与网络快捷面板使用同一层可编辑字段与固定底部完整设置入口。菜单沿用现有 Glide。

设备、采样率和 LAN 的“当前仍用”来自 ready 会话快照，仅有差异才显示。节点、Hub 和 Room 没有后端已应用快照，不用当前偏好冒充运行事实；这些字段沿用明确的下次启动说明。复制当前入口只取快照 hostAddress / health performerPort，HTTPS 非 off 且有 URL 时始终优先，包括入口错误状态。创作 OSC 使用创作测试配置，保留异步加载与运行操作的禁用边界；Room 仍按 telematic 独立显示。

本轮用真实 React 组件生成静态 DOM，复核池塘设置窗口、暖沙节点页、暗场音频页和粗野音频快捷面板，已检查节点保留、字段对齐和底部入口。该检查使用测试数据，不冒充原生 App 或硬件验收。生产构建通过；新增自动化覆盖搜索、跨分类保留状态、快照差异、节点偏好共享、当前 URL 复制与创作 OSC 归属。
