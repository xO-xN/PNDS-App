什么是 PNDS 演奏系统 What is the PNDS Performance System

PNDS 池谱（Platform for Networked Digital Score）是创作与演奏网络数字乐谱电子音乐的平台：PNDS App 是演出现场运行工程的 macOS Host，把 Node.js 服务器与声音引擎架设在本地网络，就地构成演出环境；PNDS Template 是为 AI Coding 预备的工程起点——框架已备好实用工具，你的作品只写在少数几个特定文件里。 PNDS (Platform for Networked Digital Score) is a platform for creating and performing networked digital-score electronic music: the PNDS App is the macOS host that runs projects on stage, hosting the Node.js server and sound engine on the local network for a performance environment on the spot; the PNDS Template is a starting point prepared for AI coding — the framework ships the practical tools, and your work lives in just a few specific files.

从 Template 开始 Start from the Template

Template 是一个为 AI Coding 预备的 PNDS 工程起点：框架内已备好实现作品的实用工具，你的作品只写在少数几个特定文件里——边界清晰，简单明了。 The Template is a PNDS starting point prepared for AI coding: the framework ships the practical tools for realizing a work, and your creation lives in just a few specific files — simple and clear.

PNDS · 技术框架 PNDS · TECHNICAL FRAMEWORK

一场 PNDS 演出的技术框架 The Technology Behind a PNDS Performance

PNDS App 将 PNDS 工程定义的 Node.js 服务器架设在本地网络，就地构成数字乐谱演出环境；在此基础上，PNDS 还支持跨互联网的多地实时共奏。 The PNDS App hosts the Node.js server defined by a PNDS project on the local network, forming a digital-score performance environment on the spot; on this foundation, PNDS also supports real-time multi-site performance across the internet.
